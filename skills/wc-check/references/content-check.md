# 内容与事实检查

本文档专门处理内容层面的问题：中心是否保持、论据是否支撑、推理是否成立、事实是否准确。

---

## 一、中心保持检查

### 检查目标

正文是否围绕内容准备确认的中心判断展开？有无偏离或扩大结论？

### 从哪里获取原定中心？

**来源优先级**：
1. 内容准备阶段的中心判断
2. 用户明确的立意和观点
3. 开头承诺的核心问题或收获
4. 正文标题或第一段的主题

### 检查维度

**1. 对象是否一致？**
- 原定讨论"新手"，正文变成"所有人"
- 原定讨论"短视频"，正文变成"所有内容形式"

示例：
```
✗ 原定中心：新手做短视频的三个误区
  正文内容：所有做内容的人都会犯的错误
  问题：扩大了对象范围

✓ 修复：将"所有做内容的人"改回"新手做短视频"
```

**2. 条件是否一致？**
- 原定讨论"没预算的情况"，正文变成"通用方法"
- 原定讨论"2024 年抖音"，正文变成"所有平台所有时期"

示例：
```
✗ 原定中心：没预算时如何冷启动
  正文内容：做内容的通用方法
  问题：去掉了"没预算"这个关键条件

✓ 修复：补充"这个方法特别适合没预算的新手"
```

**3. 结论是否一致？**
- 原定说"可能有效"，正文说成"一定有效"
- 原定说"有风险"，正文说成"完全可行"

示例：
```
✗ 原定中心：这个方法在某些情况下可能有效
  正文内容：这个方法绝对有效，所有人都应该用
  问题：扩大了结论范围

✓ 修复：保持"可能有效"的判断力度，补充适用条件
```

**4. 话题是否一致？**
- 原定讨论"涨粉"，正文变成"变现"
- 原定讨论"做内容"，正文变成"做生意"

示例：
```
✗ 原定中心：如何快速涨粉
  正文内容：涨粉不重要，变现才重要
  问题：话题从"涨粉"偏离到"变现"

✓ 修复：要么调整开头改为"涨粉和变现的关系"，要么正文回到"涨粉"
```

### 处理方式

**轻微偏离**：
- 调整正文表达，收窄到原定范围
- 保持中心不变，删除偏离部分

**严重偏离**：
- 标注为 P0 问题
- 说明原定中心 vs 实际内容的差异
- 需要用户确认：是调整正文还是调整中心？

## 二、论据支撑检查

### 检查目标

每个重要判断是否有对应材料支持？案例是否超出其能证明的范围？

### 什么是"重要判断"？

**需要论据支撑的判断**：
- 因果判断（"A 导致 B"）
- 效果判断（"这个方法有效"）
- 规律总结（"通常""大部分""所有"）
- 否定判断（"这个方法不行"）

**不需要特别支撑的表达**：
- 作者的个人感受（"我觉得这很重要"）
- 事实陈述（"抖音是短视频平台"）
- 已确认的前提（材料中明确的事实）

### 检查维度

**1. 案例是否超出能证明的范围？**

**个例 → 只能证明"可能性"，不能证明"普遍规律"**

示例：
```
✗ "我的一个学员三个月涨粉 50 万，所以这个方法对所有人都有效。"
  问题：一个案例不能证明"所有人"

✓ "我的一个学员三个月涨粉 50 万，说明这个方法是有可能做到的。"
  或："我观察了 20 个用这个方法的账号，80% 在三个月内涨粉超过 10 万。"
```

**2. 相关是否推出因果？**

**相关 ≠ 因果，需要补充机制解释**

示例：
```
✗ "我发现涨粉快的账号都每天发三条，所以每天发三条就能涨粉快。"
  问题：相关不能直接推出因果，可能是涨粉快的账号有精力每天发三条

✓ "我发现涨粉快的账号都每天发三条。可能是因为高频更新提高了账号权重，也可能是因为他们内容质量好、有精力多发。单纯增加频率不一定有用，关键还是内容质量。"
```

**3. 数据来源是否明确？**

**真实数据 vs 假设示意 vs 凭空编造**

示例：
```
✗ "这个方法能让你三个月涨粉 50 万。"
  问题：数据来源不明，无依据

✓ "我用这个方法，三个月从 2000 粉涨到 5 万。"
  （作者自己的真实数据）

✓ "假如你现在有 2000 粉，用这个方法，三个月可能涨到 1-5 万。"
  （假设示意，明确标注"假如""可能"）
```

**4. 从一个指标跳到整体效果？**

**单一指标不能等于整体成功**

示例：
```
✗ "这个方法让我播放量涨了 10 倍，所以非常有效。"
  问题：如果目标是变现，播放量高但转化低，方法就不算有效

✓ "这个方法让我播放量涨了 10 倍。如果你的目标是涨粉，这个方法有效；如果目标是变现，还要看转化率。"
```

### 处理方式

**论据不足**：
- 删除无依据的结论
- 或缩小结论范围（"所有人" → "大部分新手"）
- 或补"可能""通常"等限定词

**论据错配**：
- 调整结论，匹配论据能证明的范围
- 或补充必要的机制解释

**数据来源不明**：
- 标明是假设示意（"假如""比如"）
- 或删除具体数字，改为定性描述

## 三、推理连贯检查

### 检查目标

从前提到结论的路径是否完整？观众能否理解因果关系？

### 常见推理跳步

**1. 从现象直接跳到建议**

缺少："为什么会这样"的机制解释

示例：
```
✗ "播放量高但没人咨询，说明你的内容不精准。所以要精准定位。"
  问题：从现象（播放量高没咨询）跳到建议（精准定位），缺少机制

✓ "播放量高但没人咨询，说明吸引来的是泛流量，不是精准人群。比如你卖课，但内容只讲娱乐段子，观众看完就走了。精准定位就是让内容和产品匹配，吸引真正有需求的人。"
  （补充机制：为什么不精准 → 泛流量 vs 精准人群 → 怎么做到精准）
```

**2. 用"显然""当然"掩盖跳步**

示例：
```
✗ "内容质量好，显然就能涨粉。"
  问题：用"显然"掩盖推理跳步，质量好不一定涨粉（还需要曝光、定位等）

✓ "内容质量好是涨粉的必要条件，但不是充分条件。还需要精准定位和足够曝光。"
```

**3. A → C 缺少 B**

示例：
```
✗ "多发内容就能涨粉。"
  问题：A（多发）→ C（涨粉），缺少 B（为什么多发能涨粉？）

✓ "多发内容 → 增加曝光机会 → 更多人看到 → 涨粉可能性增加。但前提是内容质量过关，否则发再多也没用。"
  （补充 B：增加曝光机会）
```

### 检查标准

**关键跳步必须补足**：
- 从问题到原因（补机制解释）
- 从原因到建议（补具体做法）
- 从前提到结论（补推理过程）

**次要跳步可以保留**：
- 观众可以自行推断的常识
- 不影响核心理解的细节

### 处理方式

**补足机制解释**：
```
原句："播放量低，所以要优化标题。"
补充："播放量低可能是标题不吸引人，观众划过去了。标题要在 3 秒内勾住观众，让他们想点进来看。"
```

**补足中间步骤**：
```
原句："内容好就能变现。"
补充："内容好 → 观众信任你 → 愿意听你推荐 → 购买转化提高。"
```

## 四、事实准确检查

### 检查目标

数据、经历、对话是否来自确认材料？假设是否明确标注？

### 检查维度

**1. 数字（粉丝数、收入、播放量）**

**来源分类**：
- 真实数据（材料确认）→ 直接使用
- 假设示意（编造用于解释）→ 必须标注"假如""比如"
- 无来源（凭空编造）→ 删除或改为假设

示例：
```
✗ "我的学员三个月涨粉 50 万。"
  （如果材料中没有这个学员）

✓ "比如一个账号三个月涨粉 50 万，那他用的方法可能是……"
  （假设示意，明确标注"比如"）

✓ "我观察过一个账号，三个月从 2000 涨到 5 万。"
  （作者真实观察）
```

**2. 用户经历（"我的学员""我做过一个项目"）**

**来源分类**：
- 用户确认的真实经历 → 直接使用
- 编造用于解释 → 改为假设示意
- 无法确认 → 删除或改为泛指

示例：
```
✗ "我有个学员叫小王，他用这个方法三个月涨粉 10 万。"
  （如果用户没有提到小王）

✓ "我见过有人用这个方法三个月涨粉 10 万。"
  （泛指，不具体到某个人）

✓ "假如一个新手用这个方法，可能三个月涨粉 1-5 万。"
  （假设示意）
```

**3. 对话（"他跟我说"）**

**来源分类**：
- 用户材料中的真实对话 → 可以使用
- 编造的对话 → 删除或改为"有人会问"

示例：
```
✗ "我朋友跟我说，你这个方法真有用。"
  （如果用户没有提到这段对话）

✓ "有人可能会问，这个方法真的有用吗？我的答案是……"
  （改为预期疑问）
```

**4. 假设案例的标注**

**必须标注的情况**：
- 编造的具体数字
- 编造的人物和情节
- 编造的对话

**标注方式**：
- "假如""比如""举个例子"
- "我们可以想象这样一个场景"
- "假设你现在……"

示例：
```
✗ "你现在有 2000 粉，用这个方法三个月能涨到 5 万。"
  （断言，但实际是编造的预测）

✓ "假如你现在有 2000 粉，用这个方法，三个月可能涨到 1-5 万。"
  （假设示意，明确标注）
```

### 处理方式

**真实数据** → 保留

**假设示意** → 补标注（"假如""比如"）

**无来源编造** → 删除或改为：
- 泛指（"我见过有人"）
- 假设示意（"假如"）
- 定性描述（"涨粉效果可能比较好"）

## 五、检查执行流程

### 第一步：快速扫描全文

标记这些信号词：
- "所有人""任何人""一定""必然"（可能扩大结论）
- "我的学员""我做过"（可能虚构经历）
- 具体数字（"50 万""三个月"）（可能无来源）
- "所以""因此""导致"（可能推理跳步）

### 第二步：对照原定中心

**检查清单**：
- [ ] 对象是否一致？
- [ ] 条件是否一致？
- [ ] 结论是否一致？
- [ ] 话题是否一致？

### 第三步：检查论据支撑

**逐个判断检查**：
- 这个判断有论据吗？
- 论据能证明这个范围吗？
- 从相关到因果，补机制了吗？
- 数据来源明确吗？

### 第四步：检查推理连贯

**逐段检查**：
- A → C 之间有 B 吗？
- 用"显然""当然"掩盖跳步了吗？
- 观众能理解因果关系吗？

### 第五步：检查事实准确

**逐条核对**：
- 数字是真实的还是编造的？
- 经历是确认的还是虚构的？
- 对话是真实的还是编造的？
- 假设案例标注了吗？

## 六、常见问题与处理示例

### 示例一：中心跑偏

```
原定中心：新手做短视频的三个误区
正文内容：所有做内容的人都要避免的五个错误

问题：
1. 对象扩大（新手 → 所有人）
2. 范围扩大（短视频 → 所有内容）
3. 数量变化（三个 → 五个）

处理方式：
→ 收窄到原定范围："新手做短视频容易犯三个错误"
→ 或者确认是否要调整中心
```

### 示例二：论据不足

```
原句："这个方法对所有人都有效，因为我的一个学员三个月涨粉 50 万。"

问题：
1. 一个案例不能证明"所有人"
2. 没有说明学员的起点、内容类型、投入等条件

处理方式：
→ 缩小结论："这个方法是有可能做到的，我的一个学员三个月涨粉 50 万。"
→ 或补充条件："这个方法对新手账号比较有效。我的一个学员从 0 开始，三个月涨粉 50 万。"
```

### 示例三：推理跳步

```
原句："内容质量好就能涨粉。"

问题：
1. A（质量好）→ C（涨粉），缺少 B
2. 质量好是必要条件，不是充分条件

处理方式：
→ 补机制："内容质量好 → 观众愿意看完和互动 → 平台推荐更多 → 涨粉。但前提是定位精准，吸引的是目标人群。"
```

### 示例四：虚构数据

```
原句："我的学员小王三个月涨粉 50 万，收入 30 万。"

问题：
1. 如果材料中没有小王，这是虚构经历
2. 具体数字无来源

处理方式：
→ 改为假设："假如一个账号三个月涨粉 50 万，按 1% 转化率算，可能收入几万到几十万不等。"
→ 或泛指："我见过有人三个月涨粉 50 万。"
```

### 示例五：相关推因果

```
原句："我发现涨粉快的账号都每天发三条，所以每天发三条就能涨粉快。"

问题：
1. 相关不等于因果
2. 可能是涨粉快的账号有精力发三条，而不是因为发三条所以涨粉快

处理方式：
→ "我发现涨粉快的账号都每天发三条。但不一定是因为发得多，可能是他们内容质量好、有精力多发。单纯增加频率不一定有用，关键还是内容质量。"
```
