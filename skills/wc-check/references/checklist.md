# 检查清单

本文档提供五大维度的具体检查项，供 wc-check 执行时调用。每个检查项都要引用原句、标注位置、说明问题。

## 使用说明

- 不是所有检查项都会在每篇稿件中出现问题
- 按优先级（P0/P1/P2）决定修订顺序
- 每个问题必须引用原句+说明为什么在这个语境下有问题
- 不只贴标签（"AI 味""剧透"），要说清楚具体问题

---

## 维度一：内容与事实

### 1.1 中心保持检查

**检查目标**：正文是否围绕内容准备确认的中心判断展开？

**具体检查**：
- 开头和正文讨论的是同一个问题吗？
- 正文结论是否扩大了原定范围？（原来说"新手"，正文说成"所有人"）
- 是否偏离到相关但不同的话题？（原来讨论"涨粉"，正文变成"变现"）

**判定标准**：
- 中心判断的对象、条件、程度应与内容准备一致
- 允许表达方式调整，不允许立场改变

### 1.2 论据支撑检查

**检查目标**：每个重要判断是否有对应材料支持？

**具体检查**：
- 每个"因为""所以""导致"的因果判断，是否有机制解释或案例支撑？
- 案例是否超出其能证明的范围？（一个成功案例不能证明"所有人都适用"）
- 数据来源是否明确？是真实数据还是假设示意？

**判定标准**：
- 个例 → 只能证明"可能性"，不能证明"普遍规律"
- 相关 → 不能直接推出因果
- 假设 → 必须明确标注"假如""比如"

### 1.3 推理连贯检查

**检查目标**：从前提到结论的路径是否完整？

**具体检查**：
- A → C 之间是否缺少 B？（从现象直接跳到建议，缺少机制解释）
- 观众能否理解因果关系？（需要专业知识才能理解的跳步）
- 是否用"显然""当然"掩盖推理跳步？

**判定标准**：
- 关键跳步必须补足，不能只靠"显然"
- 次要跳步观众可推断的可以保留

### 1.4 事实准确检查

**检查目标**：数据、经历、对话是否来自确认材料？

**具体检查**：
- 数字（粉丝数、收入、播放量）是否来自材料确认？
- 用户经历（"我的学员""我做过一个项目"）是否属实？
- 对话（"他跟我说"）是否真实发生？
- 假设案例是否明确标注身份？

**判定标准**：
- 真实数据 → 直接使用
- 假设示意 → 必须标注"假如""比如""举个例子"
- 无法确认 → 删除或改为假设

## 维度二：结构与衔接

### 2.1 开头承诺兑现检查

**检查目标**：开头承诺的具体收获在正文中是否实际交付？

**具体检查**：
- 开头说"随便说几个问题你就明白"，正文讲了几个问题？
- 开头说"背后有个技巧"，正文交付了什么技巧？
- 开头说"三个前提"，正文列举了哪三个？

**判定标准**：
- 数量承诺必须兑现（说三个就要有三个）
- 内容承诺必须兑现（说技巧就要给具体做法，不能只给原理）
- 价值承诺必须兑现（说"低投入高回报"，正文要体现轻松和有用）

### 2.2 段落推进检查

**检查目标**：每段是否有新增信息？

**具体检查**：
- 连续 2-3 段是否只是换说法重复同一内容？
- 每段的作用是什么？（交代事实/表达判断/提供理由/举例/连接）
- 删掉这段，观众会少理解什么？

**判定标准**：
- 同义重复 → 删除或合并
- 必要复述（帮助理解）→ 保留
- 无作用的过渡 → 删除

### 2.3 衔接自然检查

**检查目标**：相邻段落之间有无联系？

**具体检查**：
- 从 A 段到 B 段，观众能否理解为什么要讲 B？
- 是否突然从案例跳到建议，缺少机制解释？
- 是否从问题跳到另一个问题，缺少总结或过渡？

**判定标准**：
- 关键跳转必须有衔接（案例 → 机制 → 建议）
- 并列关系可以直接列举（"第一个""第二个"）
- 自然推进不需要"那么接下来"等空转过渡

### 2.4 结尾合理检查

**检查目标**：结尾是否完成任务？

**具体检查**：
- 是否落回判断、说明选择条件或下一步行动？
- 是否强行升华到"时代""人性"等大词？
- 是否加了无关的销售号召？（内容目的不是卖货）
- 是否只是重复前文，没有收束？

**判定标准**：
- 完成任务即可，不需要"金句"结尾
- 没有卖货目的 → 不加销售号召
- 强行升华 → 删除，回到具体判断

## 维度三：口播表达

### 3.1 流式接收检查

**检查目标**：观众逐句接收时，能否理解当前句？

**具体检查**：
- 指代是否明确？（"它""这个""那个"指什么？）
- 观众需要回看前文才能理解吗？
- 代词距离被指对象是否太远？（超过 2 句话）

**判定标准**：
- 指代不明 → 改为具体名词
- 距离太远 → 重复主语
- 需要回看 → 调整表达

### 3.2 一遍听懂检查

**检查目标**：句子是否过长或过碎？

**具体检查**：
- 一句话超过 50 字且没有停顿？
- 连续短句堆叠，听起来像电报？（"做内容。要有观点。观点要清楚。"）
- 句子结构复杂，需要反复听才能理解？

**判定标准**：
- 过长 → 拆分成 2-3 句，保持自然停顿
- 过碎 → 合并成自然句，不失去节奏
- 复杂 → 简化结构，保持口语化

### 3.3 真人讲述检查

**检查目标**：是否像对着观众讲，还是在表演"我正在想"？

**具体检查**：
- 是否连续自问自答？（"为什么会这样呢？其实啊……那怎么办呢？我告诉你……"）
- 是否模拟犹豫和思考过程？（"嗯……这个怎么说呢……让我想想……"）
- 是否把整理稿件的过程写成正文？（"首先我想说……然后我们再看……最后总结一下……"）

**判定标准**：
- 连续自问自答（超过 2 次）→ 改为直接陈述
- 模拟犹豫（无信息增量）→ 删除
- 整理过程 → 改为面向观众的讲述

### 3.4 信息密度检查

**检查目标**：是否不断解释"接下来我要讲什么"而不直接讲内容？

**具体检查**：
- 是否频繁使用"那么接下来我们来看""首先我想说"等过渡？
- 删掉这些过渡，内容是否更清楚？
- 过渡是否有信息增量？（预告作用 vs 空转）

**判定标准**：
- 无信息增量的过渡 → 删除
- 有预告作用的过渡（"先说结论，再说原因"）→ 保留
- 频率过高（每段都有）→ 大部分删除

## 维度四：作者文风

### 4.1 个性表达保留检查

**检查目标**：用户原有的判断方式、有辨识度的说法是否保留？

**具体检查**：
- 用户说"推荐嘎嘎的"，是否改成"效果非常好"？
- 用户说"这个事儿挺扯的"，是否改成"这个现象值得商榷"？
- 用户的判断力度（"完全错""可能有问题"）是否被调整？

**判定标准**：
- 有辨识度的说法 → 保留（除非明显是 AI 生成痕迹）
- 判断力度 → 保持用户原意
- 个人态度 → 保留（"我觉得""说实话"适度使用）

### 4.2 对标文风执行检查

**检查目标**：指定对标时，是否采用了对标的语言特点？

**具体检查**：
- 句式是否匹配？（对标多用短句 → 成稿也多用短句）
- 用词是否匹配？（对标多用口语 → 成稿避免书面语）
- 节奏是否匹配？（对标快节奏 → 成稿不拖沓）

**判定标准**：
- 有明确对标要求 → 必须执行
- 无对标要求 → 保持自然口播即可

### 4.3 口头禅适度检查

**检查目标**：是否只靠堆口头禅制造真人感？

**具体检查**：
- "说实话""老实说""真的"等口头禅频率？（每段都有 → 过度）
- 删掉口头禅，内容是否仍然成立？
- 口头禅是否有真实语气作用，还是机械堆砌？

**判定标准**：
- 适度使用（全文 2-3 次）→ 保留
- 过度使用（每段都有）→ 删减一半以上
- 无作用的口头禅 → 删除

### 4.4 机械套用检查

**检查目标**：是否照搬参考作者的原句、例子、数据？

**具体检查**：
- 是否只把"我"改成"他"，其他内容照抄对标？
- 是否照搬对标的例子（"东北雨姐""三个前提"等具体案例）？
- 是否照搬对标的数据（"两千万粉丝""三个月涨粉 50 万"）？

**判定标准**：
- 照搬对标例子/数据 → 必须替换成本篇材料
- 学习对标句式/节奏 → 允许
- 学习对标文风 → 允许

## 维度五：机器化表达与姿态

### 5.1 代入式权威检查

**检查目标**：是否替观众预设想法再纠正？

**具体检查**：
- 是否出现"你肯定以为""很多人都觉得""你脑子里是不是浮现出"？
- 被否定的观众想法是否有依据？（材料提到/常见误解 vs 凭空编造）
- 是否先编个无知观众，再站到更高位置纠正？

**判定标准**：
- 有依据的常见误解 → 可以提（"很多人把做内容理解成写文章"）
- 无依据的预设 → 删除，改为直接陈述作者判断
- 替观众编脑内画面 → 删除

**改写示例**：
- 原句："你肯定以为做内容就是写文章，错了！"
- 改为："做内容不只是写文章，更重要的是……"

### 5.2 凭语气补证据检查

**检查目标**：删掉语气词后，结论是否仍然成立？

**具体检查**：
- 是否频繁使用"真相是""你必须明白""核心就是"等强调？
- 删掉"真相是"，剩下的内容是否有理由支撑？
- 是否用"绝对""一定""所有"等绝对词扩大结论？

**判定标准**：
- 有理由支撑 → 删掉语气词，保留内容
- 无理由支撑 → 补理由、缩小结论或删除该判断
- 绝对词过度 → 改为"通常""大部分""可能"

**改写示例**：
- 原句："这才是真正的底层逻辑！"（没说是什么逻辑）
- 改为："这背后的机制是……"（直接说机制内容）

### 5.3 空泛对照检查

**检查目标**：对照是否有具体内容？

**具体检查**：
- "普通人看表面，高手看本质"（没说表面是什么，本质是什么）
- "不是……而是……"（被否定的说法是否真实相关？对照是否有内容？）
- "从 A 到 B"（A 和 B 是否具体？转变过程是否清楚？）

**判定标准**：
- 空泛对照 → 填充具体内容或删除
- 具体对照 → 保留
- "不是……而是……"要检查是否制造认知高低

**改写示例**：
- 原句："普通人看表面，高手看本质。"
- 改为："普通人只看播放量，高手会分析完播率和互动率。"

### 5.4 为显深刻造句检查

**检查目标**：是否为了显得深刻而造空泛开场或总结？

**具体检查**：
- 是否用"在这个……的时代"开场？（"在这个信息爆炸的时代"）
- 是否用"……才是……"制造对立？（"内容的价值不在于多，而在于精"）
- 是否升华到"人性""时代""本质"等大词？

**判定标准**：
- 空泛开场 → 删除，直接进入具体判断或现象
- 空泛总结 → 删除或改为具体判断
- 有内容支撑的升华 → 可以保留

**改写示例**：
- 原句："在这个信息爆炸的时代，内容的价值不在于多，而在于精。"
- 改为：直接说"做内容不是数量越多越好，一篇精准的内容比十篇泛泛而谈更有用。"

### 5.5 按生成原则检查

**四条生成原则对应检查**：

**原则一：只替作者承担判断，不擅自替观众编想法**
- 检查所有"你肯定""很多人""观众以为"的表达
- 观众心理是否有依据？
- 无依据 → 直接讲作者判断和理由

**原则二：让理由支撑结论，不用语气补足证据**
- 检查所有强调语气（"真相""必须""核心"）
- 删掉语气词，结论是否成立？
- 不成立 → 补理由、缩小结论或删除

**原则三：按听者理解内容的顺序讲，不表演写作者想稿子的过程**
- 检查连续自问、犹豫、解释性过渡
- 是否真正提供信息？删掉后是否更清楚？
- 无信息增量 → 删除

**原则四：新增表达必须承担具体作用**
- 检查同义复述、漂亮总结、强行升华
- 这句话的作用是什么？
- 无作用 → 删除，必要复述保留

## 检查执行顺序

1. **先扫描全文找 P0 问题**（事实错误、中心跑偏、承诺未兑现、逻辑断裂）
2. **再逐段找 P1 问题**（代入式权威、推测写成事实、剧透、同义重复）
3. **最后找 P2 问题**（口播不顺、空泛表达、文风不一致、打字式自言自语）
4. **修订后全文通读**（连贯性、作者语气、口播习惯）

## 引用格式要求

每个问题必须包含：

1. **位置**：[开头] / [正文第 X 段] / [结尾]
2. **原句**：完整引用有问题的表达（10-50 字）
3. **问题**：为什么在这个语境下有问题（不只贴标签）
4. **建议**：具体怎么改，或提供 1-2 个改写候选

**示例**：
```
[正文第 2 段] "你肯定以为做内容就是写文章，错了！"
问题：无依据的代入式权威，材料中没有提到观众有这个误解
建议：改为"做内容不只是写文章，更重要的是……"（直接陈述作者判断）
```
