# 结构与衔接检查

本文档处理稿件的结构层面问题：开头承诺是否兑现、段落是否推进、衔接是否自然、结尾是否合理。

---

## 一、开头承诺兑现检查

### 检查目标

开头承诺的具体收获在正文中是否实际交付？

### 开头承诺的三种类型

**1. 数量承诺**
- "随便说几个问题你就明白了"
- "三个前提"
- "两个关键点"

**2. 内容承诺**
- "背后有个技巧"
- "核心原因"
- "底层逻辑"

**3. 价值承诺**
- "低投入、高价值"
- "简单几步就能学会"
- "你就明白了"

### 检查方法

**第一步：提取开头承诺**

从开头（特别是引子部分）提取具体承诺：
- 承诺讲几个问题/方法/前提？
- 承诺交付什么内容？（技巧/原因/方法/列举）
- 承诺什么价值？（轻松理解/快速学会/避免误区）

**第二步：在正文中定位交付**

逐段检查正文是否实际交付：
- 数量是否匹配？
- 内容是否交付？
- 价值是否体现？

**第三步：判断是否兑现**

完全兑现 → 通过
部分兑现 → 补足缺失部分或调整承诺
完全未兑现 → P0 问题，必须修复

### 常见问题

**问题一：数量不匹配**

```
开头："随便说三个问题你就明白了"
正文：只讲了一个问题

✗ 承诺三个，只交付一个

处理方式：
→ 补足两个问题
→ 或调整开头为"说一个关键问题你就明白了"
```

**问题二：内容不匹配**

```
开头："背后有个技巧"
正文：只讲了原理，没有具体操作步骤

✗ 承诺技巧（具体做法），只交付原理（为什么）

处理方式：
→ 补充具体操作步骤
→ 或调整开头为"背后有个原理"
```

**问题三：价值不匹配**

```
开头："简单几步就能学会"
正文：讲了复杂的理论体系，需要专业知识才能理解

✗ 承诺"简单"，实际很复杂

处理方式：
→ 简化正文，用通俗语言解释
→ 或调整开头为"理解这个机制需要一些基础知识"
```

### 特殊情况

**开头承诺模糊**（"你就明白了"）：
- 检查正文是否交付了清晰的理解、方法或判断标准
- 观众看完是否真的"明白了"？

**开头只制造悬念，没有具体承诺**：
- 检查正文是否解答了开头提出的问题
- 悬念是否得到合理收束？

## 二、段落推进检查

### 检查目标

每段是否有新增信息？是否只是换说法重复前面的内容？

### 什么是"新增信息"？

**有新增信息**：
- 交代新的事实
- 表达新的判断
- 提供新的理由
- 举新的例子
- 完成必要连接

**无新增信息**（同义重复）：
- 只是换说法重复前面的内容
- 没有推进理解
- 删掉后不影响整体

### 检查方法

**第一步：提取每段核心信息**

用一句话概括每段的核心内容：
- 段落 1：XXX
- 段落 2：XXX
- 段落 3：XXX

**第二步：检查是否重复**

相邻段落之间：
- 是否只是换说法说同一件事？
- 是否有新增信息？
- 删掉其中一段，会少理解什么？

**第三步：检查推进路径**

全文的信息推进是否清晰：
- 从问题 → 原因 → 解决办法
- 从现象 → 机制 → 应用
- 从错误 → 正确 → 具体做法

### 常见问题

**问题一：连续重复同一概念**

```
段落 1："做内容要有观点。"
段落 2："观点是内容的核心。"
段落 3："没有观点的内容不叫好内容。"

✗ 三段都在说"内容要有观点"，只是换说法

处理方式：
→ 合并为一段："做内容要有观点，这是内容的核心。"
→ 后两段改为推进：段落 2 讲"什么是观点"，段落 3 讲"怎么找观点"
```

**问题二：重复解释同一机制**

```
段落 1："播放量高但没人咨询，是因为吸引的是泛流量。"
段落 2："泛流量就是不精准的观众，他们不是你的目标人群。"
段落 3："目标人群才会购买，泛流量只会看看就走。"

✗ 三段都在解释"泛流量 vs 精准流量"，有一定推进但重复较多

处理方式：
→ 合并为一段："播放量高但没人咨询，是因为吸引的是泛流量——不是你的目标人群，他们看完就走，不会购买。"
```

**问题三：多次总结同一结论**

```
段落 5："所以做内容要精准。"
段落 6："这就是精准的重要性。"
段落 7："总之，精准是关键。"

✗ 三段都在总结"精准重要"，无新增信息

处理方式：
→ 删除后两段，保留一次总结
→ 或将后两段改为推进：段落 6 讲"怎么做到精准"，段落 7 讲"精准的具体标准"
```

### 必要复述 vs 同义重复

**必要复述**（可以保留）：
- 帮助理解的解释（"什么叫精准呢？就是……"）
- 换角度说明（"从观众角度看……从平台角度看……"）
- 强化记忆的关键点重复（全文只重复 1-2 次）

**同义重复**（必须删除）：
- 连续 2-3 段只是换说法
- 没有新的角度或信息
- 删掉后不影响理解

## 三、衔接自然检查

### 检查目标

相邻段落之间有无联系？观众能否理解为什么从 A 跳到 B？

### 三种衔接关系

**1. 顺承关系**（自然推进）
- 从问题 → 原因
- 从原因 → 解决办法
- 从理论 → 应用

**2. 并列关系**（同层级列举）
- 第一个问题、第二个问题、第三个问题
- 一方面、另一方面
- 方法一、方法二、方法三

**3. 转折关系**（对照或补充）
- 但是、然而、不过
- 除了 A，还有 B
- A 不行，要用 B

### 检查方法

**第一步：标注段落关系**

相邻段落之间是什么关系：
- 顺承？（从 A 推进到 B）
- 并列？（A 和 B 同层级）
- 转折？（A 与 B 对照）

**第二步：检查关系是否清楚**

观众能否理解为什么从 A 到 B：
- 顺承关系：B 是 A 的自然结果吗？
- 并列关系：A 和 B 是同一标准下的分类吗？
- 转折关系：为什么要转折？转折的理由清楚吗？

**第三步：判断是否需要补充衔接**

关系不清楚 → 补充必要的过渡或机制解释
关系清楚 → 不需要额外过渡

### 常见问题

**问题一：从案例突然跳到建议**

```
段落 2："我有个学员三个月涨粉 50 万。"
段落 3："所以你要精准定位。"

✗ 从案例直接跳到建议，缺少机制解释

处理方式：
→ 补充机制："他用的方法是精准定位——内容和产品匹配，吸引目标人群。所以你要精准定位。"
```

**问题二：并列项标准不一致**

```
段落 3："第一个问题是定位不精准。"
段落 4："第二个问题是内容质量。"
段落 5："第三个问题是不懂平台规则。"

✗ 三个问题的层级不一致（定位、质量、规则属于不同层面）

处理方式：
→ 统一层级："第一个是定位问题（不精准），第二个是内容问题（质量差），第三个是运营问题（不懂规则）"
```

**问题三：转折无理由**

```
段落 4："做内容要有观点。"
段落 5："但是数据也很重要。"

✗ 为什么突然转折？"观点"和"数据"的关系是什么？

处理方式：
→ 补充转折理由："做内容要有观点，这是内容本身。但光有观点还不够，还要看数据，验证观点是否被观众接受。"
```

### 何时需要过渡？

**需要过渡的情况**：
- 关键跳转（案例 → 机制 → 建议）
- 转折关系（为什么要转折）
- 话题切换（从 A 话题到 B 话题）

**不需要过渡的情况**：
- 并列关系（"第一个""第二个"就是过渡）
- 自然推进（观众可以理解为什么从 A 到 B）
- 已有明确连接词（"因为""所以""但是"）

## 四、结尾合理检查

### 检查目标

结尾是否完成任务？有无强行升华、无关销售或空泛总结？

### 结尾的三种类型

**1. 落回判断型**
- 回到核心观点
- 强化关键判断
- 明确适用条件

**2. 下一步行动型**
- 告诉观众接下来可以做什么
- 给出具体操作建议
- 说明注意事项

**3. 结果承诺型**（有卖货目的时）
- 说明产品如何帮助达成结果
- 给出购买理由
- 号召行动

### 检查方法

**第一步：确认内容目的**

从内容准备阶段提取：
- 这篇内容的目的是什么？（理解/学会/改变判断/购买）
- 目标受众是谁？
- 期望观众看完后有什么变化？

**第二步：检查结尾是否匹配目的**

内容目的 vs 实际结尾：
- 目的是理解机制 → 结尾应落回核心判断
- 目的是学会方法 → 结尾应给下一步行动
- 目的是购买产品 → 结尾应说明产品价值和购买方式

**第三步：检查结尾问题**

- 强行升华？（无关的"时代""人性""本质"）
- 无关销售？（内容目的不是卖货，却加销售号召）
- 空泛总结？（只重复前文，没有收束）
- 没有结尾？（正文讲完就结束，缺少收束）

### 常见问题

**问题一：强行升华**

```
正文：讲做短视频的三个技巧
结尾："这背后体现的是人性对注意力的争夺，是这个时代内容创作的本质。"

✗ 强行升华到"人性""时代""本质"，与正文内容脱节

处理方式：
→ 落回具体判断："这三个技巧的核心是精准定位。定位准了，内容自然能吸引目标人群。"
```

**问题二：无关销售**

```
正文：讲内容创作的误区
结尾："现在报名我的课程，立省 200 元，加微信 XXX。"

✗ 内容目的不是卖货（只是讲误区），结尾加无关销售

处理方式：
→ 删除销售号召
→ 或调整内容目的，在正文中自然引出课程
```

**问题三：空泛总结**

```
正文：讲了三个涨粉方法
结尾："总之，做内容要用心，要坚持，要不断学习。"

✗ 空泛总结，与正文具体方法脱节

处理方式：
→ 落回具体："这三个方法我都验证过有效。新手可以从第一个开始，先把定位做精准。"
```

**问题四：没有收束**

```
正文：讲完第三个方法
结尾：（没有结尾，正文讲完就结束）

✗ 缺少收束，观众不知道"到这里结束了"

处理方式：
→ 补充简短收束："这就是我用的三个方法。试试看，应该会有帮助。"
```

### 结尾长度控制

**简短即可**（1-3 句话）：
- 不需要重复正文所有内容
- 不需要逐条总结
- 给一个清晰的收束点即可

示例：
```
✓ "这三个技巧都不难，关键是定位要准。试试看，应该会有帮助。"
（简短收束，落回核心"定位"）

✗ "今天我们讲了三个技巧。第一个是……，第二个是……，第三个是……。总之，做内容要用心，要坚持，要不断学习，要相信自己，要保持热情……"
（冗长重复，空泛说教）
```

## 五、检查执行流程

### 第一步：开头承诺兑现检查

1. 提取开头承诺（数量/内容/价值）
2. 在正文中定位交付
3. 判断是否完全兑现

**不兑现 → 标记为 P0 问题**

### 第二步：段落推进检查

1. 提取每段核心信息
2. 检查相邻段落是否重复
3. 标记同义重复的段落

**同义重复 → 标记为 P1 问题**

### 第三步：衔接自然检查

1. 标注段落关系（顺承/并列/转折）
2. 检查关系是否清楚
3. 判断是否需要补充衔接

**关系不清楚 → 标记为 P1 或 P2 问题**

### 第四步：结尾合理检查

1. 确认内容目的
2. 检查结尾是否匹配目的
3. 标记强行升华、无关销售、空泛总结

**强行升华/无关销售 → 标记为 P1 或 P2 问题**

## 六、常见问题与处理示例

### 示例一：承诺未兑现

```
开头："随便说三个问题你就明白了。"
正文：只讲了"定位"一个问题

问题：承诺三个，只交付一个

处理方式：
→ 补足两个问题："除了定位，还有内容质量和更新频率两个问题。"
→ 或调整开头："说一个核心问题你就明白了。"
```

### 示例二：段落重复

```
段落 3："做内容要有观点。"
段落 4："观点是内容的核心。"
段落 5："没有观点就不是好内容。"

问题：三段同义重复

处理方式：
→ 合并为一段："做内容要有观点，这是内容的核心。"
→ 后两段改为推进：段落 4 讲"什么是观点"，段落 5 讲"怎么找观点"
```

### 示例三：衔接突兀

```
段落 4："我有个学员三个月涨粉 50 万。"
段落 5："所以你要精准定位。"

问题：从案例直接跳到建议，缺少机制

处理方式：
→ 补充机制："他的方法是精准定位——让内容和产品匹配，吸引目标人群。所以你要精准定位。"
```

### 示例四：结尾升华

```
正文：讲短视频涨粉的三个技巧
结尾："这背后是人性对注意力的争夺，是时代的本质。"

问题：强行升华，与正文脱节

处理方式：
→ 落回具体："这三个技巧的核心是精准。定位准了，涨粉自然快。新手可以从第一个开始试。"
```

### 示例五：综合问题

```
开头："随便说几个问题你就明白了。"

段落 1："做内容要有观点。"
段落 2："观点很重要。"
段落 3："没有观点不行。"
段落 4："所以要做出好内容。"

结尾："总之，我们要不断学习，不断进步，相信自己，保持热情。"

问题：
1. 承诺"几个问题"，只讲了"观点"一个
2. 段落 1-3 同义重复
3. 段落 4 空泛，没有具体建议
4. 结尾空泛说教，与正文无关

处理方式：
→ 合并段落 1-3："做内容要有观点，这是内容的核心。"
→ 补充段落 4："观点可以从三个地方来：自己的经历、同行的分歧、观众的困惑。"
→ 调整开头："说一个核心问题你就明白了。"
→ 调整结尾："观点是做内容的基础。新手可以先从自己的经历入手，把真实感受说出来。"
```
