# 修订原则与边界

本文档说明修订模式下的执行规则、权限边界和改写策略。

## 核心原则

修订的目标是：**让稿件更清楚、更自然、更符合口播习惯，同时保留作者立场、个性表达和真实语气。**

不是：
- 改变作者观点
- 抹平个性表达
- 把口语改成书面语
- 删除所有语气词

---

## 一、修订权限

### 允许修改（不需要确认）

**1. 表达方式优化**
- 调整句式，保持意思不变
- 修复指代不明（"它""这个"改为具体名词）
- 拆分过长句子或合并过碎句子
- 调整用词，保持语气和力度

**2. 删除无信息增量的表达**
- 同义重复（连续 2-3 句说同一件事）
- 空转过渡（"那么接下来我们来看"）
- 空泛总结（没有新内容的金句）
- 打字式自言自语（"首先我想说""然后我们再看"）

**3. 修复明显问题**
- 代入式权威（无依据的"你肯定以为"）
- 凭语气补证据（"真相是"后面没内容）
- 空泛对照（"普通人看表面高手看本质"没说具体内容）
- 为显深刻造句（"在这个时代"等空泛开场）

**4. 补足必要衔接**
- 基于已有材料补充机制解释
- 段落之间缺失的过渡（观众能理解为什么从 A 到 B）
- 指代不明时重复主语

### 不允许修改（会破坏稿件）

**1. 作者的中心判断和立场**
- 不能改变观点方向
- 不能软化或强化判断力度（除非是凭语气补证据）
- 不能替换核心论据

**2. 已确认的事实和材料**
- 不能改变数据、案例、经历
- 不能补充材料中没有的新内容（除非是合理推断且标明）
- 不能删除关键论据

**3. 用户明确要求保留的表达**
- 前序环节锁定的内容
- 用户纠正过的措辞
- 指定对标的文风特点

**4. 有辨识度的个人说法**
- "推荐嘎嘎的""挺扯的"等个性表达
- 作者的说话习惯（适度的口头禅）
- 真实的情绪表达

### 需要确认才能修改（重大调整）

**1. 删除整段（超过 50 字）**
- 说明为什么这段无作用或有问题
- 给出删除后的影响
- 等待用户确认

**2. 调整核心论据的顺序**
- 说明调整理由（现有顺序的问题）
- 给出调整后的顺序
- 等待用户确认

**3. 补充材料中没有的新内容**
- 说明为什么需要补充
- 标明是"推断"或"假设示意"
- 等待用户确认

**4. 改变对标要求的文风特点**
- 说明对标要求与实际问题的冲突
- 给出最小调整方案
- 等待用户确认

## 二、修订流程

### 第一步：处理 P0 问题（阻断性）

**P0 问题必须修复**：
- 事实错误
- 中心跑偏
- 承诺未兑现
- 逻辑断裂

**处理方式**：
- 事实错误 → 删除或改为假设示意
- 中心跑偏 → 调整回原定中心（需要确认）
- 承诺未兑现 → 补充交付或调整承诺
- 逻辑断裂 → 补足机制解释

### 第二步：处理 P1 问题（严重）

**P1 问题强烈建议修复**：
- 代入式权威
- 推测写成事实
- 剧透
- 同义重复

**处理方式**：
- 代入式权威 → 删除无依据预设，改为直接陈述作者判断
- 推测写成事实 → 补"可能""通常"，或标明假设身份
- 剧透 → 调整开头表达，保留悬念
- 同义重复 → 删除重复，保留一次清楚的表达

### 第三步：处理 P2 问题（改善）

**P2 问题建议优化**：
- 口播不顺
- 空泛表达
- 文风不一致
- 打字式自言自语

**处理方式**：
- 口播不顺 → 修复指代、调整句式
- 空泛表达 → 填充具体内容或删除
- 文风不一致 → 统一语气、称呼、句式
- 打字式自言自语 → 删除整理过程，改为面向观众讲述

### 第四步：全文通读检查

修订完成后，从头到尾读一遍，检查：
- **连贯性**：段落之间是否自然衔接？
- **作者语气**：是否保留了作者的判断力度和说话方式？
- **口播习惯**：是否适合一遍听懂？
- **问题解决**：P0/P1 问题是否全部修复？

## 三、改写策略

### 策略一：从生成规则改起，不打补丁

**错误做法**（打补丁）：
- 发现一个"你肯定以为"就删一个
- 把所有"真相是"都删掉
- 把长句都拆短

**正确做法**（改规则）：
- 检查所有预设观众想法的表达是否有依据
- 检查所有结论是否有理由支撑
- 检查句子是否一遍听懂（而不是机械拆短）

### 策略二：保留必要的口播特征

**必要的复述（帮助理解）→ 保留**
```
✓ "这个方法的核心是精准定位。什么叫精准定位呢？就是……"
（第二句是对"精准定位"的解释，有信息增量）
```

**个人态度和语气（适度使用）→ 保留**
```
✓ "我觉得这个方法真的很有用。"
（作者的真实态度）

✓ "说实话，大部分人都会犯这个错。"
（适度的口头禅，全文 2-3 次可接受）
```

**真实的犹豫和转折（有信息增量）→ 保留**
```
✓ "一开始我也这么想，但后来发现……"
（作者的真实经历和认知变化）
```

**面向观众的称呼和互动 → 保留**
```
✓ "你看，这就是为什么……"
✓ "咱们可以从两个角度来看……"
```

### 策略三：不过度删减

**错误**：把所有过渡都删成电报文
```
✗ 原句："那为什么会这样呢？其实背后的原因是……"
✗ 改成："原因是……"（太突兀）
✓ 改成："背后的原因是……"（保留必要过渡）
```

**错误**：把个性表达都改成标准话术
```
✗ 原句："这个数据推荐嘎嘎的。"
✗ 改成："这个数据效果非常好。"（抹平个性）
✓ 保留："这个数据推荐嘎嘎的。"（个性表达）
```

**错误**：把口语都改成书面语
```
✗ 原句："做内容这个事儿，其实挺难的。"
✗ 改成："内容创作难度较大。"（书面语）
✓ 保留："做内容这个事儿，其实挺难的。"（口语自然）
```

### 策略四：保持判断力度

作者说"完全错"，不改成"可能有问题"（除非是凭语气补证据）。

**检查标准**：
- 删掉语气词后，内容是否成立？
- 成立 → 保留判断力度
- 不成立 → 补理由或缩小结论

示例：
```
原句："这种做法完全错了，因为……"
删掉"完全"后："这种做法错了，因为……"
→ 有理由支撑，保留"完全错"

原句："这绝对是最好的方法。"
删掉"绝对"后："这是最好的方法。"
→ 没有比较其他方法，"最好"无依据
改为："这是我验证过有效的方法。"
```

## 四、具体改写方法

### 方法一：删除代入式权威

**识别特征**：
- "你肯定以为""很多人都觉得"
- 无依据的观众预设

**改写方式**：
```
原句："你肯定以为做内容就是写文章，错了！"
改为："做内容不只是写文章，更重要的是……"
（直接陈述作者判断）
```

### 方法二：补理由，去语气词

**识别特征**：
- "真相是""核心就是""你必须明白"
- 删掉语气词后内容不成立

**改写方式**：
```
原句："真相是，做内容不是越多越好。"
改为："做内容不是越多越好，因为观众注意力有限。"
（补理由）

原句："这才是真正的底层逻辑！"
改为："这背后的机制是：观众看到标题后……"
（说清楚机制内容）
```

### 方法三：填充空泛对照

**识别特征**：
- "普通人看表面，高手看本质"
- 没说表面是什么，本质是什么

**改写方式**：
```
原句："普通人关注数量，高手关注质量。"
改为："与其每天发 5 条泛泛而谈，不如每周精心打磨 2 条有具体方法的内容。"
（说清楚数量和质量的具体差异）
```

### 方法四：删除空泛开场

**识别特征**：
- "在这个……的时代"
- "我们不得不面对一个事实"

**改写方式**：
```
原句："在这个信息爆炸的时代，内容的价值不在于多，而在于精。"
改为："做内容不是数量越多越好。一篇精准的内容比十篇泛泛而谈更有用。"
（删除空泛开场，直接进入具体判断）
```

### 方法五：删除同义重复

**识别特征**：
- 连续 2-3 句只是换说法，没有新信息

**改写方式**：
```
原句："做内容要有观点。观点要清楚。清楚的观点才有用。"
改为："做内容要有清楚的观点。"
（三句合并成一句）

原句："这个方法很重要。真的非常重要。我必须强调它的重要性。"
改为："这个方法很重要，因为……"
（删除重复，补理由）
```

### 方法六：删除整理过程

**识别特征**：
- "首先我想说""然后我们再看""最后总结一下"
- 把写作过程表演成正文

**改写方式**：
```
原句："首先我想说，做内容要有观点。然后我们再看，观点要怎么来。最后总结一下，观点的三个来源。"
改为："做内容要有观点。观点可以从三个地方来：……"
（删除整理过程，直接讲内容）
```

### 方法七：修复指代不明

**识别特征**：
- "它""这个""那个"指代不清
- 观众需要回看才能理解

**改写方式**：
```
原句："做内容需要观点。它要清楚。"
改为："做内容需要观点。观点要清楚。"
（重复主语"观点"）

原句："方法 A 适合新手，方法 B 适合老手。它的优势是……"
改为："方法 A 适合新手，方法 B 适合老手。方法 B 的优势是……"
（明确指出是"方法 B"）
```

### 方法八：补足机制解释

**识别特征**：
- 从现象直接跳到建议
- 缺少"为什么"的解释

**改写方式**：
```
原句："播放量高但没人咨询，说明你的内容不精准。所以要精准定位。"
改为："播放量高但没人咨询，说明吸引来的是泛流量，不是精准人群。比如你卖课，但内容只讲娱乐段子，观众看完就走了。精准定位就是让内容和产品匹配，吸引真正有需求的人。"
（补充机制：为什么不精准 → 怎么做到精准）
```

## 五、修订边界提醒

### 保留真实语气

去 AI 味 ≠ 去掉所有语气词

**要删除的**：
- 无依据的"你肯定""很多人"
- 无内容支撑的"真相是""核心就是"
- 为显深刻的"在这个时代""人性的本质"

**要保留的**：
- 作者的判断力度（"完全错" vs "可能有问题"）
- 个人的说话习惯（"说实话""老实说"适度使用）
- 真实的转折和犹豫（有信息增量）
- 面向观众的互动（"你看""咱们"）

### 结合其他维度

修订不是孤立的，要结合五大维度：

1. **内容与事实**：改写后是否改变了作者立场？论据是否仍然成立？
2. **结构与衔接**：删除重复后，段落是否仍然连贯？
3. **口播表达**：改写后是否仍然自然口播？
4. **作者文风**：是否保留了个性表达？
5. **机器化表达**：是否解决了代入式权威等问题？

### 不要矫枉过正

**错误倾向一：过度删减**
- 把所有过渡都删掉 → 变成电报文
- 把所有口头禅都删掉 → 失去真实感
- 把所有强调都删掉 → 失去作者态度

**错误倾向二：过度书面化**
- 把"做内容这个事儿"改成"内容创作"
- 把"挺难的"改成"难度较大"
- 把"你看"改成"可以看到"

**错误倾向三：抹平个性**
- 把"推荐嘎嘎的"改成"效果很好"
- 把"挺扯的"改成"值得商榷"
- 把"真的很有用"改成"具有一定价值"

## 六、修订完成自查

修订完成后，用以下清单自查：

### 问题修复检查
- [ ] P0 问题全部修复
- [ ] P1 问题全部或大部分修复
- [ ] P2 问题在不改变核心内容的前提下优化

### 内容保留检查
- [ ] 作者的中心判断和立场保持不变
- [ ] 已确认的事实和论据保持不变
- [ ] 有辨识度的个人说法保留
- [ ] 作者的判断力度保持不变

### 质量检查
- [ ] 全文连贯，段落之间自然衔接
- [ ] 符合口播习惯，一遍能听懂
- [ ] 保留作者语气和说话方式
- [ ] 没有过度删减或过度书面化

### 交付准备
- [ ] 整理出 3-5 条关键修改说明
- [ ] 只说实质性修改，不列举所有细节
- [ ] 完整口播稿按自然段排版
- [ ] 不混入编辑备注、检查标签、评分

## 七、常见修订示例

### 示例一：综合问题修订

**原稿**：
```
你肯定想过，为什么我发了那么多内容，数据还是不好？真相是，你根本不懂内容的底层逻辑。普通人看热度，高手看转化。这才是真正的本质。那么接下来我们来看，怎么提升转化率。首先我想说，转化率的核心在于精准。什么叫精准呢？就是你的内容要精准。精准的内容才有转化。所以，做内容一定要精准。
```

**问题识别**：
- "你肯定想过"无依据预设（P1）
- "真相是""底层逻辑"凭语气补证据（P1）
- "普通人高手"空泛对照（P1）
- "真正的本质"空泛升华（P2）
- "那么接下来我们来看"整理过程（P2）
- "首先我想说"整理过程（P2）
- "精准""精准的内容""做内容一定要精准"同义重复（P1）

**修订稿**：
```
很多人遇到的困惑是：发了很多内容，数据还是不好。问题可能不在数量，而在目标不清楚。如果目标是卖课，那播放量高但没人咨询，就是无效流量。要看的是咨询转化率，而不只是播放量。

怎么提升转化率？核心是让内容和产品匹配。比如你卖的是自媒体课程，内容就要讲自媒体的具体方法，而不是泛泛的励志故事。这样吸引来的观众，才是真正有需求的人。
```

**关键修改说明**：
1. 删除无依据的观众预设，改为"很多人遇到的困惑"
2. 删除"真相是""底层逻辑"等语气词，直接说具体问题
3. 将"普通人高手"的空泛对照改为具体例子（播放量 vs 转化率）
4. 删除"那么接下来""首先我想说"等整理过程
5. 合并三次"精准"的同义重复，用具体例子说明什么是精准

### 示例二：保留个性表达

**原稿**：
```
说实话，这个方法推荐嘎嘎的。我用了三个月，数据真的好得不得了。老实说，以前我也不信，但试了之后发现真的有用。
```

**错误修订**（抹平个性）：
```
✗ 这个方法效果非常好。我使用了三个月，数据表现优异。起初我持怀疑态度，但实践证明确实有效。
```

**正确修订**（保留个性）：
```
✓ 说实话，这个方法推荐嘎嘎的。我用了三个月，粉丝从 2000 涨到 5 万。以前我也不信，但试了之后发现真的有用。
（保留"说实话""推荐嘎嘎的""真的有用"等个性表达，只补充具体数据）
```

### 示例三：修复口播不顺

**原稿**：
```
方法 A 适合新手。方法 B 适合老手。它的优势是简单。它的缺点是效果慢。所以要看情况选择。情况不同选择不同。
```

**问题识别**：
- 句子过碎（P2）
- 指代不明（"它"指什么？）（P2）
- 同义重复（"看情况""情况不同"）（P1）

**修订稿**：
```
方法 A 适合新手，方法 B 适合老手。方法 A 的优势是简单，但效果慢；方法 B 复杂一些，但见效快。新手可以从方法 A 入手，熟练后再用方法 B。
```

**关键修改说明**：
1. 合并过碎句子，保持自然节奏
2. 补充指代不明的"它"（明确是"方法 A"）
3. 删除"看情况选择"的同义重复，给出具体选择建议
