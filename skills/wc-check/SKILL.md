# 全稿检查与修订

wcskill 系列的第四阶段，调用名：`$wc-check`。

承接完整口播稿（开头+正文）或独立输入，执行：恢复前序约束 → 检查五大维度问题 → 根据模式交付修订稿或诊断报告。

自带检查规则与修订原则，不依赖其他 Skill。不照搬 dbs-ai-check 的默认流程。

## 两种运行模式

| 模式 | 触发条件 | 交付内容 |
|------|----------|----------|
| **修订模式（默认）** | 用户要求"检查""修订""改""去 AI 味""完成稿件" | 修订后的完整口播稿 + 简述关键修改（3-5 条） |
| **诊断模式** | 用户明确说"只检查不改""给诊断报告""先别改" | 按优先级分层的问题清单，每条引用原句+位置+具体问题 |

用户说"可以""继续""改吧"时进入修订；说"先看看问题"时保持诊断。同一窗口可以先诊断、讨论后再修订。

## 不变量

- 保留已确认的目的、受众、中心判断、事实边界和关键立场，不在检查时静默换题或调整观点。
- 检查所有问题必须引用原句、标注位置、说明为什么在这个语境下有问题，不只贴标签。
- 修订不改变作者立场，只改表达方式。删除整段、调整论据顺序前要说明理由。
- 保留作者有辨识度的表达、个人态度和真实语气；去 AI 味不等于抹平个性。
- 同一窗口已确认的信息直接复用；跨窗口接收时恢复前序阶段的关键约束。
- 默认在对话中交付；用户要求或已授权文件工作流时才保存，不自动发布或发送。

## 1. 承接稿件与前序约束

恢复这篇稿件的目的、受众、中心判断、开头承诺的收获、正文框架、事实边界及表达要求。

完整稿件应包含开头和正文；只有正文时先说明缺少开头，仍可检查正文部分，但不能检查"开头承诺是否兑现"。只有开头时建议先完成正文再检查。

从前序环节提取的关键约束：

- **内容准备阶段**：目的、受众、中心观点、论据来源、事实边界、话题入口
- **正文写作阶段**：采用的框架、关键高光或交付、对标文风要求、确认的补写内容
- **开头生成阶段**：使用的方法或样本、开头承诺的具体收获、接入位置

没有前序环节时，从稿件本身提取中心、结构和承诺；缺少关键信息时标为"待确认边界"，不编造前提。

## 2. 检查维度与严重度

读取 [检查清单](references/checklist.md)，按五大维度逐项检查。按文本顺序逐处检测，每个问题必须：

1. **引用原句**：完整引用有问题的表达（10-50 字）
2. **标注位置**：段落位置或开头/正文的具体区间
3. **说明问题**：为什么在这个语境下有问题，不只贴"AI 味""剧透"标签
4. **标注严重度**：🔴 强信号 / ⚠️ 中信号 / 💡 弱信号
5. **给出建议**：具体怎么改，或提供 1-2 个改写候选

### 严重度分级

**🔴 强信号（必须修复）**
- 事实错误：虚构数据、伪造经历、错误归因
- 中心跑偏：正文偏离内容准备确认的中心判断
- 承诺未兑现：开头承诺的收获在正文中没有交付
- 逻辑断裂：关键推理跳步，观众无法理解因果
- 代入式权威：替观众预设想法再纠正，无依据的"你肯定以为"

**⚠️ 中信号（强烈建议修复）**
- 推测写成事实：把假设、可能、推断写成确定事实
- 剧透：开头提前透露正文的关键答案、方法、机制
- 同义重复：连续 2-3 句表达同一内容，无新增信息
- 凭语气补证据："真相是""核心就是"删掉后内容不成立
- 空泛对照："普通人看表面高手看本质"没说具体内容

**💡 弱信号（需结合语境判断）**
- 口播不顺：指代不明、句子过碎、转写式表达
- 空泛表达：没有具体内容的漂亮总结、强行升华
- 文风不一致：前后语气、称呼、句式风格差异大
- 打字式自言自语：把整理稿件的过程写成正文

### 检查顺序

按文本顺序从头到尾扫描，命中几处就列几处。不按严重度分组，而是按出现位置顺序列出，每条标注严重度符号。

修订模式下，🔴 强信号必须修复，⚠️ 中信号强烈建议修复，💡 弱信号结合语境优化。诊断模式下，所有问题都列出，由用户决定是否修改。

## 3. 五大维度检查规则

### 维度一：内容与事实

**检查目标**：中心是否保持、论据是否支撑、推理是否成立、事实是否准确。

读取 [内容与事实检查](references/content-check.md)，逐项执行：

1. **中心保持检查**：正文是否围绕内容准备确认的中心判断展开？有无偏离或扩大结论？
2. **论据支撑检查**：每个重要判断是否有对应材料支持？案例是否超出其能证明的范围？
3. **推理连贯检查**：从前提到结论的路径是否完整？有无跳步？观众能否理解因果？
4. **事实准确检查**：数据、经历、对话是否来自确认材料？假设是否明确标注？

**常见问题**：
- 把个例推广为普遍规律
- 从相关推出因果
- 把"可能""也许"的推测写成确定事实
- 虚构用户经历或客户结果
- 补写的假设案例未标明身份

### 维度二：结构与衔接

**检查目标**：段落是否推进、衔接是否自然、开头承诺是否兑现、结尾是否合理。

读取 [结构与衔接检查](references/structure-check.md)，逐项执行：

1. **开头承诺兑现**：开头承诺的具体收获（理解机制/学会方法/避免误区）在正文中是否实际交付？
2. **段落推进检查**：每段是否有新增信息？是否只是换说法重复前面的内容？
3. **衔接自然检查**：相邻段落之间有无联系？观众能否理解为什么从 A 跳到 B？
4. **结尾合理检查**：结尾是否完成任务？有无强行升华、无关销售或空泛总结？

**常见问题**：
- 开头说"随便说几个问题你就明白"，正文只讲了一个问题
- 连续 3 段都在解释同一个概念，只是换了说法
- 从案例突然跳到建议，中间缺少机制解释
- 没有卖货目的却加"现在下单立省 200"

### 维度三：口播表达

**检查目标**：是否适合一遍听懂、是否像真人讲述、是否有打字式自言自语。

读取 [检查清单](references/checklist.md) 中“维度三：口播表达”，逐项执行：

1. **流式接收检查**：观众逐句接收时，能否理解当前句？指代是否明确？
2. **一遍听懂检查**：句子是否过长或过碎？有无需要反复听才能理解的表达？
3. **真人讲述检查**：是否像对着观众讲，还是在表演"我正在想"的过程？
4. **信息密度检查**：是否不断解释"接下来我要讲什么"而不直接讲内容？

**常见问题**：
- "那么这个问题呢，其实我们可以从三个角度来看，第一个角度是……"（打字式自言自语）
- "它、这个、那个"等指代不明，观众需要回看才知道指什么
- 连续自问自答："为什么会这样呢？其实啊，是因为……那怎么办呢？我告诉你……"
- 句子过碎："做内容。要有观点。观点要清楚。清楚才有用。"

### 维度四：作者文风

**检查目标**：是否保留作者表达特点、是否机械套用参考、是否只剩口头禅模仿。

读取 [检查清单](references/checklist.md) 中“维度四：作者文风”，逐项执行：

1. **个性表达保留**：用户原有的判断方式、有辨识度的说法是否保留？
2. **对标文风执行**：指定对标时，是否采用了对标的语言特点（句式、用词、节奏）？
3. **口头禅适度**：是否只靠堆口头禅（"说实话""老实说""真的"）制造真人感？
4. **机械套用检查**：是否照搬参考作者的原句、例子、数据，只改了主语？

**常见问题**：
- 用户说"推荐嘎嘎的"，改成"效果非常好"（抹平个性）
- 指定学某作者，结果只学到"说实话""老实说"等口头禅
- 照搬对标作者的例子，只把"我"改成"他"
- 前半段第一人称亲切，后半段第三人称说教

### 维度五：机器化表达与姿态

**检查目标**：是否有代入式权威、空泛对照、凭语气补证据、为显深刻造句。

读取 [机器化表达检查](references/ai-patterns-check.md)，这是最难检查的维度，需要结合语境判断。

**四条生成原则对应检查**：

1. **只替作者承担判断，不擅自替观众编想法**
   - 检查"你肯定以为""很多人都觉得""你脑子里是不是浮现出"等表达
   - 观众的心理、错误认知、异议是否有依据（材料提到、常见误解）？
   - 无依据时，应直接讲作者的判断和理由，不先编个观众想法再纠正

2. **让理由支撑结论，不用语气补足证据**
   - 检查"真相是""你必须明白""核心就是"等强调语气
   - 删掉语气词后，结论是否仍然成立？
   - 不成立时，应补理由、缩小结论或删除该判断

3. **按听者理解内容的顺序讲，不表演写作者想稿子的过程**
   - 检查连续自问、犹豫、解释性过渡（"那么接下来我们来看""首先我想说"）
   - 这些表达是否真正提供信息？删掉后是否更清楚？
   - 不为"像真人"保留无信息增量的过渡

4. **新增表达必须承担具体作用**
   - 检查同义复述、漂亮总结、强行升华
   - 一句话是在交代事实、表达判断、提供理由、举例还是完成必要连接？
   - 对没有新增内容的表达进行删改，口播中帮助理解的必要复述可保留

**常见问题示例**：

**代入式权威**：
- "你肯定以为做内容就是写文章，错了！"（无依据预设观众想法）
- 改为："很多人把做内容理解成写文章，但实际上……"（有依据的常见误解可以提）

**凭语气补证据**：
- "这才是真正的底层逻辑！"（语气强，但没说是什么逻辑）
- 改为："这背后的机制是……"（直接说机制内容）

**空泛对照**：
- "普通人看表面，高手看本质。"（没说表面是什么，本质是什么）
- 改为：具体说普通人看什么、高手看什么、差异在哪

**为显深刻造句**：
- "在这个信息爆炸的时代，内容的价值不在于多，而在于精。"（空泛开场）
- 改为：直接进入具体判断或现象

**重要边界**：
- "不是……而是……"等句式并非在所有语境下都有问题
- 要检查被否定的说法是否真实相关、对照是否有内容、是否制造认知高低
- 单纯换掉连接词可能保留同样的姿态，要改表达方式

## 4. 修订执行规则

读取 [修订原则与边界](references/revision-rules.md)，按以下规则修订：

### 修订权限

**允许修改**：
- 表达方式（不改立场，只改怎么说）
- 论据顺序（保持逻辑，优化理解顺序）
- 删除同义重复、空泛表达、无信息增量的过渡
- 修复指代不明、句子过碎、打字式表达
- 补足必要的机制解释或衔接（基于已有材料）

**不允许修改**：
- 作者的中心判断和立场
- 已确认的事实和论据（只能调整表达）
- 用户明确要求保留的表达
- 有辨识度的个人说法（除非明显是 AI 生成痕迹）

**需要确认才能修改**：
- 删除整段（超过 50 字）
- 调整核心论据的顺序
- 补充材料中没有的新内容
- 改变对标要求的文风特点

### 修订流程

按文本顺序从头到尾修改，🔴 强信号必须修复，⚠️ 中信号强烈建议修复，💡 弱信号结合语境优化。修改完成后全文通读检查：是否仍然连贯、是否保留作者语气、是否符合口播习惯。

### 修订原则

**从生成规则改起，不打补丁**：
- 不是"发现一个代入式权威就删一个"，而是"检查所有预设观众想法的表达是否有依据"
- 不是"把所有'真相是'都删掉"，而是"检查结论是否有理由支撑"
- 不是"把长句都拆短"，而是"检查是否一遍听懂"

**保留必要的口播特征**：
- 必要的复述（帮助理解）
- 个人态度和语气（"我觉得""说实话"适度使用）
- 真实的犹豫和转折（有信息增量）
- 面向观众的称呼和互动（"你看""咱们"）

**不过度删减**：
- 不把所有过渡都删成电报文
- 不把个性表达都改成标准话术
- 不把口语都改成书面语

## 5. 交付与说明

### 修订模式交付

按文本顺序逐处修改，每修改一处立即说明：

```
修改 1（🔴）：[开头第 2 段] "你肯定以为做内容就是写文章，错了！" → "做内容不只是写文章，更重要的是……"（去无依据的代入式权威）

修改 2（⚠️）：[正文第 3 段] "甚至你的内容越有深度，数据就越差" → "甚至你的内容越有深度，反而越难涨粉"（去剧透）

修改 3（⚠️）：[正文第 4-6 段] 合并同义重复，保留第 4 段"做内容要有观点"，删除第 5-6 段重复表述

修改 4（💡）：[正文第 8 段] "那么接下来我们来看第二个问题，第二个问题其实就是……" → "第二个问题是……"（去打字式自言自语）
```

**修订完成后**：输出完整修订稿 + 修订说明（改了几处，重点改了什么）。

### 诊断模式交付

按文本顺序逐处列出问题，每条包含：严重度 + 位置 + 原句 + 问题 + 建议。

**格式**：
```
🔴 [开头第 2 段] "你肯定以为做内容就是写文章，错了！"
问题：无依据的代入式权威，材料中没有提到观众有这个误解
建议：改为"做内容不只是写文章，更重要的是……"（直接陈述作者判断）

⚠️ [正文第 3 段] "甚至你的内容越有深度，数据就越差"
问题：剧透了正文要解释的核心机制
建议：改为"甚至你的内容越有深度，反而越难涨粉"（保留反常，不透露机制）

⚠️ [正文第 4-6 段] "做内容要有观点""观点很重要""没有观点不行"
问题：同义重复，三段都在说"观点重要"，无新增信息
建议：合并为一段，后两段改为推进（什么是观点/怎么找观点）

💡 [正文第 8 段] "那么接下来我们来看第二个问题，第二个问题其实就是……"
问题：打字式自言自语，无信息增量
建议：直接说"第二个问题是……"
```

诊断后用户说"改吧""可以修改"时，转入修订模式，按诊断结果执行修改。

## 6. 续接与停止

- 用户补充材料或澄清立场后，更新相关检查结果，不重做全部检查
- 用户只想改某一维度时（"只去 AI 味""只检查逻辑"），聚焦该维度，简述其他维度状态
- 修订后用户要求"再检查一遍"时，对修订稿执行完整检查流程
- 检查完成即结束，不自动进入下一阶段或保存文件

## 完成标准

**完成标准**：
- 🔴 强信号全部修复
- ⚠️ 中信号全部或大部分修复
- 💡 弱信号在不改变核心内容的前提下优化
- 保留作者立场、个性表达、文风特点
- 全文连贯、符合口播习惯

**诊断模式**：
- 所有维度检查完成
- 每个问题都有位置、原句、具体说明、改写建议
- 按文本顺序列出，每条标注严重度
- 不只贴标签，说明为什么在这个语境下有问题
