# 信息收集：每个问题服务一个设计决定

先从已给材料提取下表内容，再追问缺口。完整信息包可以一次接收，聊天时不要逐行念表。

| 所需信息 | 用来决定什么 | 模糊时怎么追问 |
| --- | --- | --- |
| 业务、主要产品或服务、价格、交付内容、当前目标 | 需要让用户相信什么，内容之后可以发生什么行动 | 请描述最近一笔业务从接触到交付的经过；区分报价与实际成交 |
| 目标对象、最近遇到的难题、已经尝试的办法、选择顾虑 | 对谁说、从哪里开始解释、展示什么证据 | 请还原一个人来求助时的具体情形；没有真实客户则标明设想 |
| 本人经历、参与过的项目、负责的环节、结果与局限 | 哪些话可以由本人说，哪些身份与承诺还撑不住 | 选一件最能体现能力的事，问清本人做出的判断和动作 |
| 现有内容、观众反馈、转化与交付情况 | 当前给人的印象与期望差在哪 | 请指出一条最能代表自己或最不满意的作品及原因 |
| 自然说话方式、出镜接受度、希望保留的性格、表达边界 | 话术、内容形式和相处感是否可持续 | 更容易对着人讲、边做边讲，还是整理后写？能否提供一段平常表达 |
| 具体同行或替代方案、客户为何选择它们 | 差异体现在哪里，是否影响选择 | 有链接就读样本；没有时先给自身方向，不编造竞争空白 |

## 本人沟通的核心顺序

已给的信息不重问。缺失时依次补齐以下四组，每次只聊一个主题、问一到两个问题：

1. **产品与价格**：具体卖什么、如何交付、实际常见成交金额。多产品时分清主要收入产品与引流产品；报价含糊时问通常实际支付多少。
2. **履历与实力**：相关年限、承担过的职责、可核对的成果或资质。没有业务案例时追问相关工作或亲历经验；案例笼统时还原客户起点、本人动作和结果。旁观别人的案例只能作为认知材料。
3. **客户理解程度**：对问题和解决办法熟悉到哪里，哪些概念可以直接讲、哪些要解释。不确定时问客户来咨询前通常研究过什么、首先问什么。
4. **竞争环境与自身专长**：同行常见角色和表达、客户为何选择他们；不了解同行时至少明确本人擅长讲清步骤、分析选择还是承担实际交付，竞争判断保留待查。

四组已有基本判断就进入报告。自然表达和愿景已有则承接，缺失则按影响补问或注明暂定，不再要求额外交一套材料。愿景尚未成形时，从真实服务和希望用户获得的变化提出初步方向；不强迫用户先说出哲学口号。

## 为他人制定方案的资料入口

一次接收以下五项，提供过的不重复索取：

- 产品与人群定位报告；没有报告时接收产品、客单价和目标客户。
- 本人的经历、职责、成绩、案例与相关资质。
- 本人的性格、自然表达和出镜意愿。
- 竞争环境、代表账号及委托人观察到的空白。
- 委托人的初步人设判断、依据，以及最拿不准的地方。

收到后直接推导草案：业务与价格需要什么信任依据 → 履历能支持什么角色与承诺 → 客户理解程度适合怎样表达 → 竞争中可占据什么位置 → 本人性格能否持续执行 → 哪些假设最可能推翻方案。上游用共同愿景校准帮助方向与责任，不省略这六项业务判断。

委托人的初步意见是待检验的输入，不直接当作结论；赞成或调整都说明理由。材料不足以判断核心角色时只补决定性信息，其余在草案中列明。

## 按回答推进

只有行业标签时，先问实际提供什么帮助；只有“很厉害”的自评时，先问能展示的一件事；只有“我想显得专业”时，追问目前哪个场景让对方不放心。这些问题的答案应立即改变下一步设计，而不是只被抄进资料摘要。

客户是谁不明确时，优先从已经获得帮助的人中找共同处境。客户资料已有时，直接问尚未了解的本人能力和表达条件。多人共同出镜时，区分每个人承担的角色与可作出的承诺。

信息来自第三方时，记录转述来源，尤其保留本人意愿、实际能力和镜头表现之间的不确定性。可以给出方案草案，但不得把代运营人员的猜测写成本人已经确认的价值观。

## 材料有限时的收束

- 没有成熟业务：明确暂时验证的帮助方向，给能开始的内容和人物呈现；商业收益保留为待验证。
- 没有成功案例：用可展示的工作过程、研究过程或公开演示建立初期可信度，不补写虚构战绩。
- 没有视频样本：依据本人描述给表达建议并注明假设，不增加试拍环节。
- 缺少同行资料：标注未完成竞争核查，具体描述自身希望被记住的帮助方式，不宣称市场独有。

按对应入口收齐核心信息或给关键缺口注明假设后，就开始交付。只有会推翻核心定位的冲突需要先解决。避免以“专业调研”为由要求学员提供当前根本不存在的数据。
