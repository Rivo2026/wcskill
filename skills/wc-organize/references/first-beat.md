# 首拍截停机制

用于填写开局末尾的“对应片段｜截停机制”表。只分析整理后的正文第一拍，成品不输出以下判定过程。

以下例句均为自拟教学示例，其中的场景与数字仅用于说明判定边界。

## 先确定证据范围

先遮住第二拍以后，确认第一拍本身让观众需要补上什么信息、参与什么动作，或看见什么已落地的重量。再查看相邻拍确认语义边界、对比前件或引用归属；不能把下一拍的结果、收入、成绩或承诺借给首拍。

“说实话”一类语气前导若只修饰核心判断，先与判断合为一拍；不能单独断成首拍后停止分析。与此同时，“学会这一步，／你就能……”和“如果……，／那么……”有独立前件，不为借用后件价值而合拍。

对候选片段做中性替换：保留语法，把它换成不具备该功能的普通表达，检查相同的信息缺口或参与压力是否消失。不要删除必要句法成分，再把删坏句子造成的不完整算成悬空。

## 七种机制

| 机制 | 成立条件 | 常见误判 |
| --- | --- | --- |
| 强制对话 | 作者把当前观众叫进回答、测试、选择、看听或共同讨论：“问你个问题”“来做个测试”“今天我们来试试……” | 转述别人说话、展示广告语或纯栏目题头，不能仅凭命令句式算直接对话 |
| 悬空 | 由因为、如果、为了、对比等关系启动尚未落下的后件；或自然听觉节点上的对象尚未填入 | 逗号、没有谓语、作者还会接着讲，都不足以证明悬空 |
| 预设 | 未证明的共识、争议判断、身份意义、异常状态或对象相关性先被摆给观众，使人问“凭什么／这个对象怎么了” | 普通事实和普通修饰语，不因后面还有解释就自动成立 |
| 矛盾 | 首拍内能指认语义相撞的双方，或首拍反转了标题/已知栏目身份建立的预期 | 大结果、陌生概念和未解释状态本身不等于矛盾 |
| 发问 | 首拍已经问出具体内容缺口，例如如何、为什么、凭什么 | “问你个问题”尚未问出具体内容时只算强制对话 |
| 预设价值 | 首拍已落地、当场可衡量的信息重量：极端数值、反常时长/年龄、付费事实或有分量的证据 | 普通日期/序号不算；小起点不能借用下一拍的大成绩来增重 |
| 价值承诺 | 首拍承诺观众将获得/避免的具体能力、效果、改变或结果 | 单纯报一个主题不算；已有证据与将来收益不能混标 |

“今天我们来学叠衬衫不容易起皱的方法”既把观众拉入讨论，也承诺具体能力，可以标强制对话＋价值承诺；“今天我们来聊聊衣服”没有同样具体的能力承诺。

“你想过没有，／……”尚未问出具体内容，可能是强制对话＋悬空；不能仅凭疑问形式加上发问。

## 复合与片段定位

- 同一拍可以有多个机制，但每个机制都要有独立证据。成品每行写一个连续原文片段和一个机制，相同配对不重复。
- 按从左到右的听觉展开核对自然节点。“为了修好”先缺对象，“为了修好这把椅子，”随后仍缺动作；两层追问不同，可以用两个原文片段分别标悬空。不能任意截字符前缀，把每个没读完的词都变成缺口。
- 判断句可以分别检查观众接受与拒绝时的反应。拒绝时的“凭什么”支持预设；接受后的“然后呢”只有在明确条件、因果、转折或比较前件尚未闭合时才支持悬空。一般好奇心不够。
- 劝告整句与未解释术语可以分别成立预设：整句追问“凭什么不建议”，术语追问“这是什么”。两问确实独立时才分别保留。
- 对象相关性与关系后件分开：“楼下的修鞋铺”追问“它怎么了”，是预设；“因为这家修鞋铺……”追问因果后件，才可能是悬空。
- 表中只保留原文片段，不抽象成 `〔X〕` 模板，不展示词、词组、带槽句式、标签对等载体术语。标签碰撞可选包含双方的连续原句来定位。

## 关键边界

| 首拍及必要语境 | 应保留的判断 |
| --- | --- |
| “今天我们来试试怎样把衬衫叠得不容易起皱。” | 强制对话、发问、价值承诺分别定位 |
| “这是巷子里一家不起眼的修鞋铺，”；下一拍才揭晓高营业额 | 预设；首拍没有营业额证据，不标预设价值 |
| “一家刚开业十天的花店，”；下一拍才给出销量 | 对象意义待解释，判预设；不能因没有谓语就判悬空 |
| “一家刚开业十天的花店，一周就接到了两百份订单。”同拍成立 | 小起点和大结果均已落地，可判预设价值 |
| “我知道你不爱收拾，”后接“但……” | 可分别检查未证明判断的预设与转折前件的悬空 |
| 收纳教学账号首拍“今天不整理房间了。” | 已知栏目预期与首拍决定相撞，可判矛盾 |
| “说实话，肯认错的人才适合当领导。” | 语气前导与判断同拍，再核对判断是否预设及是否真的有碰撞，不把前导独立判悬空 |
| 展示海报上的“现在就出发”“你准备好了吗？”；以及被展示的歌词、纯系列题头 | 不把展品中的命令或问题当成作者对当前观众的截停 |

样例锁定功能边界，不是照词匹配的答案库。证据不足的候选不登记；全部不成立时 `hooks: []`，不补空表、疑点清单或解释段。源文残缺到必要判断无法完成时保留原文，并在最终回复简短说明未完成范围，不伪造机制或通过结果。
