# Jev FS 选择器使用说明

## 简介

Jev FS 选择器使用 TypeSafe AI 的 Jev 模型，**评估用不同 Few-Shot 模板写开头的效果**，推荐最能吸引观众的那个。

**核心逻辑**：不是判断"正文有什么特征"，而是判断**"用哪个 FS 写出来的开头最吸引人"**。

- **速度快**：< 1 秒返回结果
- **成本低**：单次约 $0.000168（约 0.0012 元人民币）
- **准确性高**：直接评估开头效果，提供 5 个 FS 的完整对比

## 快速开始

### 1. 基础用法

```bash
python3 scripts/jev_selector.py <正文文件路径>
```

**示例**：
```bash
python3 scripts/jev_selector.py content.txt
```

**输出**：
```

   置信度：88%
   开头吸引力：79分

📊 各 FS 开头吸引力评分:
  FS-004: 84分 (被选中概率: 9%)
  FS-001: 79分 (被选中概率: 91%)
```

### 2. 强制指定 FS

当你想测试某个特定 FS 的开头效果时：

```bash
python3 scripts/jev_selector.py content.txt FS-002
```

## 核心逻辑变化（V3）

### V1/V2 的错误逻辑（已废弃）

```
分析正文特征 → 判断适合哪个导向 → 判断有哪些素材 → 推荐 FS
```
**问题**：这是在分析正文本身，而不是在判断开头效果

### V3 的正确逻辑（当前版本）

```
假设用 FS-001 写开头 → 这个开头能吸引人吗？效果如何？
假设用 FS-002 写开头 → 这个开头能吸引人吗？效果如何？
假设用 FS-003 写开头 → 这个开头能吸引人吗？效果如何？
假设用 FS-004 写开头 → 这个开头能吸引人吗？效果如何？
假设用 FS-005 写开头 → 这个开头能吸引人吗？效果如何？

→ 选效果最好的那个
```

**核心**：评估开头效果，不是分析正文特征

## Jev 评估的是什么？

### FS-001（反常归因）
- **开头效果**：用'A正面→B负面'的反常关系制造困惑
- **评估标准**：能否制造强烈的认知冲突？观众会不会想知道'为什么'？

### FS-002（形象反差）
- **开头效果**：用'普通人+大成果+简单方法'制造价值倒挂
- **评估标准**：能否制造价值倒挂感？观众会不会想学'怎么做到'？

### FS-003（判断缺口）
- **开头效果**：用'你符合几条'制造自审焦虑
- **评估标准**：能否制造自审焦虑？观众会不会想对照'我符合几条'？

### FS-004（双驱动）
- **开头效果**：用'优势变陷阱'制造认知冲击
- **评估标准**：能否制造'优势变陷阱'的冲击？观众会不会既想理解又想自审？

### FS-005（联系缺口）
- **开头效果**：用'看似无关的AB的联系'制造时代洞察感
- **评估标准**：能否制造'看似无关的联系'？观众会不会想知道'它们怎么联系上的'？

## 决策规则

| 置信度 | 开头吸引力 | 建议 |
|--------|-----------|------|
| ≥ 80% | ≥ 70分 | ✅ **直接使用推荐的 FS** |
| ≥ 50% | ≥ 60分 | ⚠️ **推荐使用，但可能需要打磨** |
| < 50% | - | ⚠️ **置信度较低，但可以尝试吸引力最高的 FS** |

## 在 Python 代码中使用

```python
from jev_selector import select_fs_by_opening_effect
```

## 理解输出结果

### 案例 1：高置信度推荐

```
✅ 推荐使用 FS-001
   置信度：88%
   开头吸引力：79分

📊 各 FS 开头吸引力评分:
  FS-004: 84分 (被选中概率: 9%)
  FS-001: 79分 (被选中概率: 91%)
```

**解读**：
- Jev **非常确定**（88%）FS-001 是最好的选择
- 虽然 FS-004 的吸引力更高（84分），但 Jev 认为 FS-001 更适合这篇正文
- 原因可能是：FS-001 的结构更符合正文的叙事方式，或者 FS-004 需要的素材不够充足

### 案例 2：低置信度但有明确建议

```
⚠️ 置信度较低（29%），但可以尝试 FS-004（吸引力70分）

📊 各 FS 开头吸引力评分:
  FS-004: 70分 (被选中概率: 43%)
  FS-001: 55分 (被选中概率: 44%)
```

**解读**：
- Jev 在 FS-004 和 FS-001 之间犹豫（概率接近）
- 但 FS-004 的吸引力更高（70分 vs 55分）
- 建议：尝试 FS-004，如果不满意再试 FS-001

## 常见问题

### Q: 为什么 FS-004 吸引力最高（84分），但 Jev 选了 FS-001（79分）？

**A**: 因为 Jev 不仅看吸引力，还看**整体适配性**。可能的原因：
- FS-001 的结构更符合正文的叙事方式
- FS-004 需要的心理机制挖掘，这篇正文不够充分
- FS-001 的"越...越..."结构更符合正文的表达习惯

### Q: 置信度很低怎么办？

**A**: 置信度低说明正文可能不太适合标准 FS，或者多个 FS 都可以。建议：
1. 看吸引力最高的那个 FS，先试试
2. 如果不满意，试试排名第二的
3. 考虑定制开头

### Q: 所有 FS 的吸引力都不高（< 60分）怎么办？

**A**: 说明这篇正文可能需要定制开头，不适合套标准 FS 模板。

## API 配置

Jev 选择器使用 TypeSafe AI 的官方 API：

- **端点**：`https://api.typesafe.ai/v1/systemone`
- **模型**：`jev-latest`
- **认证**：`Authorization: Bearer <你的apikey>`

当前公开仓库及下载包内含 TypeSafe AI API key，使用者共享同一额度。运行脚本会把输入正文的前 2,000 个字符发送到 TypeSafe AI；使用前应先告知用户并取得同意。依赖为 Python `requests`：

```bash
python3 -m pip install requests
```
