# 反常识判断器：先选内容关系，再填母版

用于依赖反常识、认知冲突或预测打断的开头，包括 FS-001。按以下顺序生成，不能先写完整开头，再补材料和检查来解释它为什么成立。不依赖外部模型。

## 1. 先取初始预期

仅依据题材、目标受众和必要情境，列约 3—5 个常见原因或结果方向，以及通常被认为有利于目标的条件。此步不提供拟写答案及正文核心解释。有现成正文时不丢弃正文，只为预期判断裁出有限输入。

这些是模型的候选预期，不是实际人群概率。不写复杂内心独白，不为了凑数编造共识。独立上下文可用且获准时隔离输入；同一上下文已经知道答案时，不声称完成盲测。

## 2. 准备少量候选关系与交付

从正文提取可选关系；获准自由创作时，可构造 2—3 组内容包。每组只保留：通常期待的 A 与 B 关系、准备提出的反常关系、成立情境、正文关键解释与收获。先选内容，不抢写完整开头；已给定事实和中心不能为制造反差改掉。

排除只重复常见原因、换同义词或加重同一缺点的候选。反常关系须相关、易懂、能够说明成立条件；少见、离奇或听不懂不等于有吸引力。正文支撑不足时回到内容构思，不能让用户为自由试写硬补材料。

## 3. 给候选分配信息

依 [流式接收与表达规则](streaming.md) 区分：开头用什么现象、反差与待解释判断建立问题；引子承诺什么收获；正文才交付什么关键答案、解释或方法。参考 FS-001 的内容分配示范，不仅参考它的句式。

结果与解释按本篇的信息作用区分，不能靠词性判断。尚未交代完整因果，也可能已揭晓关键答案；缩短、暗示或换同义词均不能消除剧透。不设置固定禁词。

## 4. 用前缀更新预期，再选定关系

为候选给出截至关键揭晓点的短前缀，保留之前已说出的全部内容；前缀变化后更新预期。预期窗口只看受众、前缀与已知同步画面／字幕，不接收后续答案或正文底稿。列出约 3—5 个自然续接，分别标记：目标结果方向、可能的解释方向。

按两个问题决定取舍：

- **关系是否有认知差异？** 对照初始预期，A 通常被认为如何影响 B，而候选提出什么不同关系。“甚至”等词会提示负面或反转方向；能接出后半句不自动否定这组关系的反常性。
- **正文答案是否提前显露？** 对照区间分配，前缀或拟填表达是否已交付关键答案，或明显指向其核心解释。若需要额外推演、补入前缀没有的信息才猜到，只能记为可能联想；单个模型列出一个猜测不能直接当作观众已猜懂。

例如已听到“教知识太多影响变现，甚至知识越有用……”后，可能接出“转化越差”；仍需判断“有用知识损害转化”是否挑战既有认识，以及为什么成立、如何处理是否还留待正文。不要为了让结尾猜不到而换掉已认可的反常关系。

排除含义容易预料且没有认知差异，或已交付正文答案的候选；选择剩余的一组。依据不足则保留不确定，不把粗略负面预判和具体解释混为一谈。

## 5. 锁定内容，再连续填母版

选定后固定成立情境、正文交付及开头的信息范围，只按母版生成句式和篇幅。需要更换核心关系时回到内容选择，不能一边填句子一边发明新机制或把解释搬进结果槽。意外程度、信息保留和内容成立应在选材时共同满足。

正常使用只交付开头。测试时分阶段保留“初始预期、候选内容包、前缀预期、选定内容包、最终稿”；不展示隐藏推理，不要求用户逐阶段审批。记录单窗口估计或真正隔离的区别，不能据此宣称已预测真实留存。
