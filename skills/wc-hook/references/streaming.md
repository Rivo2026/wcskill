# 流式接收与表达规则

“流式接收”是用户为本项目命名的工作概念：观众随着声音、画面和字幕逐步到来，更新理解、感受与预期。低注意力不等于没有理解或预判；这种预判可以很模糊，不必形成完整内心语言。

## 用于生成

1. 先安排对象、动作、关系怎样依次出现，再组织成自然口播。当前位置只能借助已经交代的信息；不能让后文替前面尚未讲清的概念解围。
2. 一处表达承担几个作用是允许的。“核心原因”既使原因待补，也预告重要的理解收益；它与前面的困境组合，才把价值关联到具体观众。
3. “为什么、如何、怎么、甚至”等词可以先产生轻微答复期待，不必等整句构成完整悬念才承认其作用。具体力度取决于语境，不是见词就判定有效。
4. 先确定本篇正文准备兑现的核心交付，再按 V8 分配信息：好奇区间用现象、素材、反差和待解释的判断建立问题，不提前透露正文的关键答案、结论、方法或步骤；引子收束悬念，提出问题或承诺价值；正文交付核心内容、兑现承诺。生成前完成这个分工，不能靠写完后的删词补救。
5. 按信息作用判断剧透，不设固定禁词，也不只禁止因果解释。FS-001 中“知识越有用，转化率越差”用于建立待解释的反常关系，后文仍需兑现为什么成立、具体如何处理；这不等于允许任意正文结论前置。若某个表达已提前给出本篇准备交付的关键答案，即使没有因果句，或只通过短语、暗示透露，也属于剧透。缩短表达、换同义词都不改变其信息作用。理解负担靠明确对象、具体表现和易懂措辞降低，不能靠提前揭晓核心交付。
6. 分别保留两种可能路径：说中观众已有但未表达清楚的感受；偏离由前文或经验支持的预期。不是每篇都需要反转。

## 用于 few-shot 标注

分析顺序：连续原文 → 有作用变化的关键词／短语 → 句级 V8 方法及组合 → 句间承接 → 可迁移作用与槽位。

在关键位置记录“已接收的信息、候选预期、新表达与前文的关系、方法、可能即时反应”。不要求每个字填满所有字段，也不把“一个人”这类对象称呼一概忽略。

- **词与词**：如“核心＋原因”，或“越强……越差”。说明谁先出现、后者怎样补全或改变前者。
- **词与句**：如“甚至”承接哪个判断，它先预告什么、后文怎样兑现。
- **句与句**：如前文抬高问题的重要性，后文用小投入承诺理解结果。除了方法标签，还要标明此刻已揭示什么、哪些关键答案与内容仍留给正文；不能只列孤立标签。
- **句级方法**：使用 V8 名称；作用说明可以另附，但不能代替方法标注。
- **即时反应**：用“有关、意外、被说中、不服、期待”等短状态，注明是推测。不要替观众写一段复杂论证。

观众预期需要依据。不能看到答案后假定所有人之前都猜同一答案，也不能编造概率。反感、困惑或早已知道，同样可能发生。

## 文字、画面和停顿

用户明确标注时，逗号代表断句，`/` 代表停顿；保留位置。区分用户标注、音视频核对、CSV 转写标点与分析切分。

“这个人”等指示词可能依赖画面。画面或字幕若已提前揭晓，不能仍按纯口播计算悬念。只有文字时说明分析范围，不捏造画面或实际秒数。

## 理论边界

本规则结合项目已讨论的增量语言理解、语境预期和自动加工研究作应用推导，不把 V8 的“劫持”“奖励预测”标签当作逐词神经测量结论，也不用“鳄鱼脑被激活”作科学解释。

来源锚点：Eberhard 等（1995），[实时口语理解](https://pubmed.ncbi.nlm.nih.gov/8531168/)；Altmann 与 Kamide（1999），[增量解释与语境预期](https://www.psycholinguistics.com/gerry_altmann/research/papers/files/Altmann_Kamide_99.pdf)；Evans 与 Stanovich（2013），[双加工理论](https://www.krigolsonlab.com/uploads/4/3/8/4/43848243/evans_and_stanovich_2013.pdf)。这些研究不直接证明某个词必然提高短视频留存，生成任务不必每次重读论文。
