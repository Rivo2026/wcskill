# 方法与分支：V8 工作目录

来源为项目《文本共性分析_V8.md》的五维、七种机制与复合分析原则。本文件将其整理为开头工作分支；属于框架实现，尚未逐种完成 few-shot 确认或效果测试。保留方法名称，不照搬必然生效的脑科学表述，不输出伪精确评分。

## 五个观察维度

| 维度 | 生成时需要的材料和动作 |
| --- | --- |
| 认知劫持：预测打断 | 从正文找出发现与有依据的既有预期之间的差异，安排预期线索和新信息出现顺序；没有差异就不强造 |
| 认知劫持：信息缺口 | 确定观众此刻能识别的待补对象，再安排后续补充；局部疑问词也可先引出小期待 |
| 奖励预测 | 从正文的实际收获反推承诺；收益、投入和兑现材料相互对应，理解收益不偷换为收入或效果保证 |
| 损失厌恶 | 从材料中提取具体、有关联的可能损失及条件，再组织提醒；不能用泛泛焦虑替代后果依据 |
| 命名精准 | 从具体处境和已有感受提炼贴切说法，让描述可识别；不为新奇强造抽象概念 |
| 人群筛选 | 对象称呼与困境、欲望、处境或门槛组合；被描述的人与实际被吸引的观看者可以不同 |

“认知劫持”含两个子机制，因此表内分两行，总体仍沿用 V8 五维。

### 信息缺口的不同分支

| 类型 | 生成顺序与所需材料 |
| --- | --- |
| 悬念缺口 | 具体对象／事件 → 尚未揭晓的部分 → 正文真实后续；不把每个强观点都改成藏答案 |
| 判断缺口 | 评价对象 → 有内容依据的评价或标签 → 可解释的判断标准；不把辱骂本身当机制 |
| 刻度缺口 | 可比较的维度 → 有依据的门槛或位置 → 对应解释；不能编造比例或把修辞数字伪装统计 |

## 七种触发机制

| 名称 | 生成时组织什么关系 |
| --- | --- |
| 认知冲突：翻转型 | 有依据的原理解与新解释相对照；不擅自编造“所有人都以为” |
| 认知冲突：悖论型 | 呈现看似相反但正文能解释的关系；不强行把两个反义词组成因果 |
| 价值倒挂 | 明确同一比较中的价值、成本、身份或回报为何与惯常排序不同；让比较口径可理解 |
| 质疑权威 | 指向真实可定位的主张，再给出质疑依据；不能先捏造权威观点 |
| 身份宣言 | 从材料里的真实立场、选择或身份边界发声，不替观众编造人人赞同的立场 |
| 反直觉结果 | 从正文已支持的结果与条件起笔，安排解释；不要求所有结果都“好事变坏事” |
| 情感共鸣 | 先呈现可识别的处境、动作或感受，再落到贴切表达；不写复杂脑内独白 |
| 社会证明 | 用真实群体行为、流行度或共识线索建立相关性；热度不能证明观点正确 |

认知冲突分两行，整体仍为 V8 七种机制。维度与机制可重叠，同一词句可以复合，不要求凑齐。

## 选择与组合

先按正文材料选择进入方式，再选具有相同表达关系的 few-shot。用户指定样本时不重新选库。不得因为当前只有 FS-001 就让所有正文都产生反常归因。

组合时标明：哪些词句先圈人，哪些预告价值，哪里出现待补关系，哪里揭晓，下一句怎样继续。每个方法保留自己的推进方式，不能统一成固定三句。

当前可试写样本见 [样本索引](library.md)。没有已整理样本的方法，可按本文件提出候选，但应说明属于方法推导，不能声称经过 few-shot 验证。
