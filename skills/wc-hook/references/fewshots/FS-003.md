# FS-003：判断缺口 → 自审驱动（列举对照）

**分类**：自审驱动型

## 1. 直接使用的迁移母版

> {引入热点概念或分类标准}，{解释这个概念/标准是什么}。{否定现有浅层标准/指出判断难点}。{重新定义判断问题}，{列举N个判断维度/前提条件，只点名不展开}。

填槽前先确定正文的核心交付：开头只制造"我是不是/我符不符合"的判断缺口，列举框架只点名维度；不得把正文的具体判断标准、详细解释提前填入任一槽位。

**正文关键答案包括**：
- 每个维度的具体标准（什么叫"内容一致"？具体怎么判断？）
- 为什么这个标准重要（为什么必须"承担风险"？）
- 正反案例对照（符合的是什么样，不符合的是什么样）

**剧透判断标准**：
- 开头只说"有N个前提/维度"，点出名字（内容一致、自我开源、承担风险）
- 不说"内容一致是指什么""为什么要承担风险"
- 如果观众听完开头就能接出具体判断标准或做法，说明剧透了

## 2. 原文范例

### 范例一："三个前提"

**原文**：
> 最近有个很火的话题叫做怎么去鉴别大博主幼年体，就是那种他虽然是刚做自媒体才起步，但你刷到了会有一种卧槽怎么才这么点粉丝的感觉。我看了圈然很多博主他们讲的这个东西其实都很浅，说的都些不害怕镜头啊，说话有逻辑这种废话。所以我今天就把这年头什么样的人还能吃上自媒体这碗饭给大家去讲清楚。整体上来说其实就三个前提啊，内容一致，自我开源、承担风险。

**结构拆解**：
1. **引入概念**："怎么去鉴别大博主幼年体"
2. **解释概念**："就是那种...卧槽怎么才这么点粉丝"
3. **否定浅层标准**："很多博主讲得都很浅...不害怕镜头啊...这种废话"
4. **重新定义问题**："什么样的人还能吃上自媒体这碗饭"
5. **列举框架**："三个前提：内容一致，自我开源、承担风险"（只点名，不展开）

**字数**：125字（口播断句后会更短）

**正文承接**：
- 第一段："首先什么叫做内容一致？"（展开第1个前提）
- 后续段落：依次展开"自我开源""承担风险"

## 4. 核心机制与必要条件

### 核心机制

**判断缺口 + 自审焦虑 + 列举对照**

观众的心理路径：
1. "我是不是X？"（自审缺口）
2. "怎么判断？"（寻求标准）
3. "对照N个标准看我符合几条"（自审对照）

### 必要条件

要使用 FS-003，正文必须满足：

1. **有可自审的分类标准**：观众能对照判断"我是哪一类""我符合几条"
2. **有列举结构**：正文是"N个前提/N种人/N个误区"的列举型
3. **有对照价值**：观众在意这个判断结果（关系到能不能做/会不会失败）

缺少任一条件，无法形成自审驱动。

### 适用正文类型

- 误区列举型：列举常见错误，让观众对照"我犯了几条"
- 能力诊断型：列举必备条件，让观众判断"我具备几条"
- 人群分类型：列举几种人，让观众判断"我是哪一种"

## 5. 生成步骤与迁移规则

### 生成步骤

1. **确认列举结构是否成立**：
   - 正文是否有"N个X"的列举框架？
   - 观众能否对照判断"我是/我有/我符合"？
   - 这个判断对观众是否重要（关系到能不能做/会不会失败）？

2. **选定或创造概念**：
   - 正文有现成概念（如"大博主幼年体"）直接用
   - 正文没有概念，创造一个可自审的分类（如"三种做IP的人"）
   - 概念必须让观众产生"我是不是"的自审

3. **划定信息边界**：
   - 开头只点列举框架的名字（"三个前提：A、B、C"）
   - 不说每个维度的具体标准
   - 不说为什么这个标准重要
   - 用"整体上来说就N个""其实就N条"制造简洁感

4. **按车厢循环逐句生成**：
   - 第1句：引入概念/分类 + 制造判断缺口
   - 第2句：否定浅层标准（可选）+ 强化判断缺口
   - 第3句：重新定义 + 列举承诺（点名不展开）

### 字数与节奏

- 总字数：80-130字（口播断句后）
- 第1句：30-50字（解释概念，制造自审）
- 第2句：20-40字（否定浅层，强化缺口）
- 第3句：30-40字（列举承诺）

### 关键词信号

常见开头模式：
- "最近有个很火的话题叫...鉴别X"
- "做X的人分N种，看看你是哪一种"
- "如果你有这N个特征，说明你..."
- "判断能不能做X，其实就看N个前提"

## 6. 与 FS-001、FS-002 的区别

| 维度 | FS-001 | FS-002 | FS-003 |
|------|--------|--------|--------|
| **核心机制** | 反常归因（认知冲突） | 形象反差（价值倒挂） | 判断缺口（自审焦虑） |
| **车厢循环模式** | 困惑 → 困惑强化 → 承诺理解 | 好奇 → 震惊+可复制 → 承诺技巧 | 判断缺口 → 恐惧点 → 列举对照 |
| **第1句车厢作用** | 建立反常关系 + 制造困惑缺口 | 预告反常 + 揭示反差 + 制造"怎么做到"缺口 | 引入概念 + 制造判断缺口（"我是不是"） |
| **第2句车厢作用** | 递进反差 + 强化困惑 | 成果强化 + 指向技巧 + 制造期待 | 否定浅层标准 + 强化判断缺口 |
| **最后一句三重作用** | ①总结反常关系 ②确立理解导向 ③承诺例子 | ①总结反差 ②确立利益导向 ③承诺技巧揭秘 | ①总结判断问题 ②确立自审导向 ③承诺列举对照 |
| **最终导向类型** | 理解驱动（想知道为什么） | 利益驱动（想复制成果） | 自审驱动（想判断自己行不行） |
| **观众最终预期** | "理解为什么会这样 → 避免错误" | "学会这个技巧 → 复制成果" | "对照N个标准 → 判断自己符不符合" |
| **情绪驱动** | 好奇 + 期待（觉得能听懂） | 贪婪 + 期待（觉得能做到） | 焦虑 + 期待（想知道自己行不行） |
| **适用正文类型** | 机制解释型、因果分析型、路径对比型 | 技巧揭秘型、方法教学型、案例拆解型 | 误区列举型、能力诊断型、人群分类型 |

## 7. 常见问题与注意事项

### 判断缺口 vs 信息缺口

- **信息缺口**（FS-001/002）：观众想知道"为什么""怎么做"（客观知识）
- **判断缺口**（FS-003）：观众想知道"我是不是""我符不符合"（自我对照）

判断缺口的核心是**自审焦虑**，不是单纯的好奇。

### 否定浅层标准的作用

第2句"别人讲得都很浅"不是必须的，但它的作用是：
1. 强化判断缺口（现有标准不靠谱）
2. 建立权威感（我给的才是真货）
3. 制造恐惧点（你可能被误导了）

如果正文没有"别人讲错了"的对比，可以省略这一句，直接进入列举承诺。

### 列举框架的呈现

开头只点名字，不展开：
- ✓ "三个前提：内容一致、自我开源、承担风险"
- ✗ "三个前提：第一个是内容要保持一致不能今天讲这个明天讲那个..."（剧透了）

### 字数灵活性

FS-003 比 FS-001/002 更灵活，因为：
- 列举项数量可变（2-5个都可以）
- 概念解释长度可变（取决于概念复杂度）
- 否定浅层标准可有可无

但总字数建议控制在 80-130 字，超过会显得拖沓。
