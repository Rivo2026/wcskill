# FS-001：反常归因 → 理解驱动（因果困惑）

**分类**：理解驱动型 - 第一子类

## 1. 直接使用的迁移母版

> {对象／人群}{具体困境}的{核心／根本／关键}原因就是{用于建立问题的反常行为或状态}，甚至{通常被认为有利于目标的条件或表现 A}越{正向变化}，{本篇关心的目标结果或能力 B}就越{负向变化}。{命名并追问尚待解释的问题，不交付关键答案}，{很小且具体的接收投入}{明确、有价值的收获承诺}。

填槽前先确定正文的核心交付：归因与递进结果只建立待解释的关系，追问与承诺只引出后续收获；不得把正文的关键答案提前填入任一槽位。

**正文关键答案包括**：
- 关键区分/分类（正文用来解释关系的核心分类，如"从技能找销路 vs 从需求倒推"）
- 机制的运作方式（为什么A会导致B的具体过程，如"低认知受众→无法转化高客单"）
- 具体表现/行为特征（关系在现实中的具体体现，如"看不上低级需求"、"慢工细活"）
- 具体案例/情境（正文用来说明的例子，如"地铁教学"、"马达克"、"柠檬水"）

**剧透判断标准**：开头的作用是制造好奇心。好奇心 = 提出问题但答案未知。如果观众听到这个表达后，能直接接出正文要交付的关键区分/方法/机制/具体做法，说明答案的一部分已经给出，好奇心被破坏了。开头可以让观众知道"正文讲什么话题"（上班与创业、流量与变现），但不能让观众接出"正文讲的具体是什么内容"（两条路径是什么、为什么取悦观众会导致赚不到钱）。

按信息作用划分，不按词表禁用。

按约 **20／26／26 字**连续生成“归因、递进、问题命名与承诺”三个表达段；总量以原文 **72 字**为参照，当前试写范围 **65—79 字**，均不含标点、空白。不插入案例、解释或第四段。保留“甚至……越……，……就越……”骨架；对象、属性、问题名称和收获措辞可以按槽位替换。字数范围仅用于本条迁移。

## 2. 完整范例

### 范例一：上班与创业（72 字）

> 一个人赚不到钱的核心原因就是你上班上多了，甚至你上班时候的工作能力越强，你自己做生意的思维就越差。什么叫按照上班的思维去创业啊，随便说几个问题你就明白了。

**正文核心交付**：区分两种出发点——从已有技能找销路 vs 从用户需求倒推产品、内容和所需能力。用短视频、课程、卖柠檬水等情境展开。

**信息分配**：开头建立”上班能力强→创业思维差”的反常关系，命名”上班思维”问题，但不讲两条路径是什么，也不提前给出需求倒推的方法。

---

### 范例二：自媒体与流量（69 字）

> 一个人做自媒体赚不到钱的核心原因就是你太会搞流量了，甚至你做的爆款视频越多，愿意给你付费的人就越少，什么叫按照取悦观众的思维去做生意呢，随便说几个后果你就明白了

**正文核心交付**：向下内容（向外归因、一步登天）吸引低认知受众 → 无法转化高客单 → 被迫做智商税或积累负债粉丝 → 陷入存量市场；真正路径是向上筛选受众。

**信息分配**：开头建立”爆款多→付费少”的反常关系，命名”取悦观众的思维”问题，但不讲向下/向上的具体分类，也不提前说明受众质量如何影响变现机制。

---

### 内容分配原则

迁移时保留这个分工：先有需要解释的关系，再用正文交付关键区分与方法。命名问题不等于已经交付答案，但不能把关键区分或方法换成一个名称提前说出来。不要照搬范例的具体商业解释。

## 2.5. 车厢循环分析（范例一）

以"上班与创业"为例标注完整车厢循环路径。

### 第1句车厢："一个人赚不到钱的核心原因就是你上班上多了"

**【进入理由】**
- 信息缺口："核心原因是什么？"（由"核心原因"这个词制造）
- 价值承诺："核心"暗示这个原因很重要

**【车厢内旅程】**
- 完结预期：给出了原因（"上班上多了"）
- 制造新困惑："怎么可能？上班多应该更有经验啊"（悖论型认知冲突）
- 使用机制：认知冲突（反常归因）
- 情绪状态：困惑 + 震惊

**【车厢末尾状态】**
- ✓ 旧预期完结情况：**部分完结**（知道原因了，但不理解为什么）
- ✓ 新缺口制造情况：**困惑缺口**（"为什么上班多反而赚不到钱？"）
- → 观众有理由进入第2句 ✓

**【信息累积】**
- 观众知道：赚不到钱的核心原因是"上班上多了"
- 观众困惑：为什么上班多是问题？这很反常

---

### 第2句车厢："甚至你上班时候的工作能力越强，你自己做生意的思维就越差"

**【进入理由】**
- 困惑缺口："为什么上班多反而赚不到钱？"（上一句制造的）

**【车厢内旅程】**
- 完结预期：没有直接解释，而是强化困惑（"甚至"预告递进）
- 制造新要素：给出更强的反常关系（"能力越强 → 思维越差"）
- 使用机制：认知冲突（递进反差）
- 情绪状态：困惑加强 + 震惊升级

**【车厢末尾状态】**
- ✓ 旧预期完结情况：**强化而非解答**（困惑升级，不是困惑消除）
- ✓ 新缺口制造情况：**更强的困惑缺口**（"为什么能力强反而思维差？这到底怎么回事？"）
- → 观众有理由进入第3句 ✓

**【信息累积】**
- 观众知道：上班多 → 赚不到钱，而且能力越强 → 思维越差
- 观众困惑升级：这两个应该是正相关的啊，为什么反而相反？

---

### 第3句车厢（最后一句）："什么叫按照上班的思维去创业啊，随便说几个问题你就明白了"

**【进入理由】**
- 累积困惑："为什么会出现这种反常关系？"（前两句累积的）

**【车厢内旅程】**
- 命名问题："按照上班的思维去创业"（把前两句的错误做法抽象成概念）
- 承诺解决："随便说几个问题就明白"
- 使用机制：命名精准 + 奖励预测 + 价值倒挂（大问题用小投入就能明白）
- 情绪状态：期待（从困惑转为期待理解）

**【车厢末尾状态：三重作用检查】**

✓ **① 阶段性总结**
- 完结开头所有预期：
  - "核心原因"已经给出（上班上多了/能力强）
  - "为什么"的困惑被明确命名（上班思维）
  - "怎么理解"的门槛被降低（几个问题就明白）
  
✓ **② 最终导向确立**
- 导向类型：**理解驱动**
- 观众预期："我要听几个问题理解为什么会这样"
- 情绪状态：好奇 + 期待（觉得能听懂）
- 驱动力：想知道为什么会出现这种反常现象
  
✓ **③ 新缺口制造**
- 具体缺口："几个问题"是什么？具体例子是什么？
- → 观众有理由进入正文第1段 ✓

**【信息累积】**
- 观众知道：原因是"上班思维"，表现是能力越强思维越差，接下来会用几个问题解释
- 观众预期：听几个简单问题就能理解这个反常机制

---

### 【车厢循环总结】

```
第1句：完结"原因是什么" + 制造"为什么这个原因"（困惑）
         ↓
第2句：强化困惑（递进反差） + 制造"为什么会这样"（更强困惑）
         ↓
第3句：命名问题 + 承诺简单解释 + 制造"具体是什么"（期待例子）
```

**最终导向**：理解驱动（想知道为什么 → 理解机制 → 避免错误）

## 3. 词性与作用对齐指南

生成时每个槽位的词性、单句作用、跨句推进关系都要与范例对齐。

### 第一段：对象、困境与反常归因

**槽位结构**：{对象}{困境}的{核心/关键}原因就是{反常行为/状态}

**词性对齐**：
- 对象：名词短语（一个人、知识IP、家长）
- 困境：动词短语（赚不到钱、变现差、做不好）
- 反常行为/状态：动词短语或形容词短语（上班上多了、太会搞流量了、学历太高了）

**单句作用**：
- “核心+原因”：同时提示答案待补和答案值得听
- “就是”：推出判断
- 反常行为/状态：建立待解释关系，但不交付正文关键答案

**紧凑原则**：能用动词别用解释（”太会搞流量” > “为了流量妥协太多”），删掉指示性修饰（”那些”、”这种”），用最简单的量词。

### 第二段：递进反差

**槽位结构**：甚至{A}越{正向变化}，{B}就越{负向变化}

**词性对齐**：
- A：名词+形容词（工作能力越强、爆款视频越多、知识体系越完整）
- B：名词+形容词（思维越差、人越少）或动词短语（越做不好）

**单句作用**：
- A：通常被认为有利于目标的条件/表现
- B：本篇关心的**可观测结果**（不是内心感受或状态）

**跨句复合作用（第一段→第二段的递进）**：
- 范例一：量（上班多）→ 质（能力强）
- 范例二：能力（会搞流量）→ 结果（爆款多）
- 不能是同义重复（学历高 → 书多）或无关跳跃

**认知冲突检查**：A与B的关系是否挑战既有认识？通常认为A强应该对B有利，但这里反而有害。”甚至”使人猜到负面方向，不等于关系失去反常性。

### 第三段：命名追问与收获承诺

**槽位结构**：{命名追问}，{小投入}{收获承诺}

**词性对齐**：
- 命名：名词短语（上班思维、取悦观众思维、知识分子思维）
- 小投入：数量词+名词（几个问题、2个点、几个情况）
- 收获：动词短语（就明白了、就清楚了）

**单句作用**：
- 命名追问：回指前面的反常关系，只说明要讲什么话题，不将答案藏进问句
- 小投入+收获：形成”大问题只需小投入就能弄明白”的价值承诺

**复合作用**：前面建立的重要问题 ↔ 很小的接收投入 ↔ 明确的收获，三者形成价值对比。

---

### 造词方法（命名思维）

第三段的”命名”不是随意填一个名词，而是**把前两句建立的错误做法抽象成一个精准概念**。

**造词步骤**：

1. **识别前两句建立的认知**
   - 观众到这里已经知道什么？
   - 前两句指出了什么错误做法？
   - 范例一：观众知道”上班”会带来某种错误思维
   - 范例二：观众知道”搞流量/做爆款”会导致赚不到钱

2. **提取核心关键词**
   - 选一个最能代表”错误来源”的词
   - 必须是前两句已经出现或暗示的词
   - 范例一：”上班”（第一句明确出现）
   - 范例二：”取悦观众”（”搞流量”的本质，第一句暗示）

3. **加抽象后缀**
   - 思维、方式、逻辑、路径...
   - 把具体行为抽象成一个可命名的概念
   - 范例一：”上班” + “思维” = “上班思维”
   - 范例二：”取悦观众” + “思维” = “取悦观众思维”

4. **检查造词质量**
   - 观众能从前两句推导出这个词吗？（有关联）
   - 这个词剧透正文关键答案了吗？（不剧透）
   - 这个词制造了”想知道具体是什么”的好奇吗？（有缺口）
   - 这个词简短精准吗？（2-4字为佳）

**造词 vs 追问的判断**：

- **适合造词**：正文涉及”思维方式对比””两种路径””错误逻辑”
  - 例如：上班思维 vs 创业思维、取悦观众 vs 筛选受众
  - 用”什么叫X思维/X方式”

- **不适合造词**：正文只是”解释反常现象””揭示机制”，不涉及思维对比
  - 例如：为什么高深内容数据好？（只是现象解释）
  - 用”为什么会出现这种反常现象”

**造词示例对比**：

| 前两句建立的认知 | 造词（适合） | 追问（替代） |
|----------------|------------|------------|
| 上班 → 思维差 | “什么叫按照上班的思维去创业啊” | “为什么上班会影响创业思维呢” |
| 搞流量 → 赚不到钱 | “什么叫按照取悦观众的思维去做生意呢” | “为什么爆款多反而赚不到钱呢” |

---

上述即时反应是推测，不要求观众意识到完整的矛盾关系。每个表达按出现顺序起作用，不提前借用后文。生成时先按词性对齐填槽，再检查单句作用和跨句推进是否成立。

## 4. 生成顺序与信息边界

### 必需输入

本方法需要从正文提取关系，**试写时必须提供**：
1. 题材与受众
2. **正文核心交付**：正文要解释的机制、方法或关键区分（梗概即可，不需要完整正文）

只给题材不给正文交付，会导致空手造观点、关系不成立或剧透问题。

### 生成步骤

1. **先取初始预期。** 按题材和受众列出常见原因及通常有利的条件，不提前把拟写解释交给预期判断。
2. **从正文提取反常关系。** 按 [反常识判断器](../counterintuitive.md)，从正文核心交付中识别”反常关系＋成立情境＋正文保留的关键答案”，参照上面的分配示范划定信息范围。先作截断前缀预判，再选定表达方式；不先把完整开头写出来。
3. **锁定内容及边界。** 固定归因、递进结果、正文关键答案与收获。能接出负面结果不自动判失败，关键解释明显提前显露则重选表达或关系。构造内容不当成已验证事实。不给正文临时换一个解释来迁就开头。
4. **按三段篇幅连续落笔。** 内容选定后，依第 3 节把对象、价值提示、反常判断、递进结果、问题命名、收获承诺逐步写出。理解负担靠清楚的对象和措辞降低，不靠提前揭晓正文。句式与篇幅从生成时遵守，不先自由扩写再压缩。

**紧凑原则**：能用动词别用解释（”太会搞流量” > “为了流量妥协太多”）；删掉指示性修饰（”那些”、”优质”）；用最简单的量词（”越多” > “播放量越高”）。

若给定正文缺少本条所需关系，评估是否可以通过合理包装达到模板强度；如果正文核心内容与反常关系完全无关，指出具体缺口并建议更换 FS。允许适度编造以达到强度（如将"数据还行"强化为"数据爆好"），但不能完全脱离正文核心内容。只借用局部作用需用户明确要求。保留用户指定的断句和停顿，不把分析切分当作真实停顿。

本条分析与范例用于指导迁移；规则效果仍待试写验证。未经认可的新稿不作为正向范例收录。

## 5. 与 FS-002 的区别

| 维度 | FS-001 | FS-002 |
|------|--------|--------|
| **核心机制** | 反常归因（A导致B的反常因果关系） | 形象反差（表面成果 vs 实际操作主体的反差） |
| **车厢循环模式** | 困惑 → 困惑强化 → 承诺理解 | 好奇 → 震惊+可复制 → 承诺技巧 |
| **第1句车厢作用** | 建立反常关系 + 制造困惑缺口 | 预告反常 + 建立成果价值 |
| **第2句车厢作用** | 递进反差 + 强化困惑 | 揭示反差 + 制造"怎么做到"缺口 |
| **最后一句三重作用** | ①总结反常关系 ②确立理解导向 ③承诺例子 | ①总结反差 ②确立利益导向 ③承诺技巧 |
| **最终导向类型** | 理解驱动（想知道为什么） | 利益驱动（想复制成果） |
| **观众最终预期** | "理解为什么会这样 → 避免错误" | "学会这个技巧 → 复制成果" |
| **情绪驱动** | 好奇 + 期待（觉得能听懂） | 贪婪 + 期待（觉得能做到） |
| **适用正文类型** | 机制解释型、因果分析型、路径对比型 | 技巧揭秘型、方法教学型、案例拆解型 |
