# 同行对照与观点提炼

收到一篇、多篇同行文案，或用户希望形成差异化、寻找正确的非共识、反驳同行观点时读取。以下是本项目的工作方法，尚不代表经过验证的通用理论。

## 先决定展示什么

先分析原文，但不默认向用户展示同行的答案及其展开路线。以下步骤中的还原、候选比较和状态评定是工作依据，不等于逐项输出要求。

用户尚无自己的判断时，先交付话题、去除预设的开放问题、带来源状态的关键事实或现象，然后与用户讨论。原文中的群体概括、价值判断、原因解释不能混入“事实或现象”。没有可核实的具体现象就说明，不凑材料。

不要以“你是否也认为……”“我们是不是可以反过来说……”提前暴露并强化同行的结论；讨论可以重新确定问题，不局限于原文的立场轴线。用户已经给出自己的判断，或明确要求评价、反驳某句话时，直接进入相关对照，无须强制重复开放讨论。

多篇文案先合并重复话题和现象，保留必要来源。内部比较共同主张与分歧；第一轮不以逐篇报告、立场排行榜或完整分歧表替代讨论。

## 1. 取得足够的对照材料

接受原始文案，也接受“同行选题＋观点”。从原文自行提取话题、选题、核心观点、支撑依据和潜在差异，不要求用户先拆解。有链接、发布时间或适用人群时一起利用。一个同行也可以开始，不设固定篇数门槛。

只拿到标题：可以分析标题字面承诺，不能猜出完整论证。

只有用户转述：标注“按用户转述讨论该主张”，不要给真实同行加上未经核对的引文。若要把具体人物作为批评对象，先核对有关原文及必要上下文；未取得原文时，可以继续分析观点本身，不把归因当成已确认事实。

用户可提供认同、异议、不同经历；没有这些时先开放讨论，不能替用户决定价值立场。

## 2. 还原主张，分开真伪与覆盖范围

用一两句话还原：对什么人、在什么情境、提出什么判断或建议、声称带来什么结果、凭什么。

保留“往往、可能、在某条件下”等限定。缺失信息标为缺失，不能替同行补强后再说原文论证充分，也不能故意删掉限定再反驳。

把同行内容当成“有人提出了这个说法”的证据。赞数、播放量与重复出现不证明说法正确；用户或 AI 不认同也不证明它错误。

对多个样本归纳时只称“这组样本中的共同说法”。记录样本范围及异议；没有代表性依据就不升级为行业共识。非共识必须有比较对象，可以是已提供同行、特定受众或有依据的行业常见看法；不能宣称全网首创。

## 3. 找到真正的分歧

逐项判断对本篇有用的差异，不必把所有方向都套一遍：

| 检查点 | 可以产生的判断 | 所需材料与失效边界 |
| --- | --- | --- |
| 事实或推理是否有错 | 直接否定具体错误，提出能够成立的替代判断 | 要有相关证据或明确推理矛盾；证据不足只能指出未被证明。 |
| 适用条件是否被省略 | 说明对哪类人、什么条件下建议会失效，并给出选择标准 | 找到会实际改变结果的条件；不能只说“因人而异”。 |
| 结果是否存在另一种解释 | 提出不同机制，解释同一结果或原观点解释不了的差异 | 需要区分解释的证据；只有可能性时保留竞争假设。 |
| 指标或目标是否错位 | 区分播放、咨询、付费、成本等目标，提出更符合本篇目的的取舍 | 用户目标和相关材料要明确；不能证明一个指标无价值或给出不存在的转化率。 |
| 建议忽略了什么代价或先后条件 | 提出替代做法、先后顺序或需要满足的门槛 | 需要说明代价怎么影响选择；不能只列风险。 |
| 结论相同但论据有缺口 | 同意结论，补出不同理由或更精确的支撑论点 | 承认结论相同，不伪装成相反观点；不同论据也要检验。 |

在用户已有自己的材料或初步判断后，形成一到三个有材料支撑的候选，不强行凑三种立场。分析时检查以下要点，对外只展示影响选择的简短判断、依据和边界；只有必要对照时才带出同行主张：

- 具体判断：一句能继续解释或证明的话。
- 与谁在哪一点不同：结论、原因、条件、指标、顺序或论据。
- 已有依据：哪条材料支持哪一步；是事实、推理还是待验证假设。
- 内容增量：观众据此能改变什么判断或选择。
- 可能推翻它的证据、适用边界及最关键缺口。

提出推荐时，优先考虑依据强度、对本篇目的的贡献和实际增量。冲突强度不能抵消证据不足。

## 4. 双向检验，继续帮助用户提炼

对同行的反例，是否也适用于我们的新主张？我们是不是把“不是每次有效”夸大成“从来没用”，把“尚未证明”夸大成“已经证伪”？

提出一个最值得追问或核实的区分问题：答案不同，应当使候选被保留、缩小、改写或放弃。不要索取与分歧无关的经历堆积。

用户补充后据此修订判断。只有反对情绪但缺乏理由时，帮助找到可检验的具体异议，不直接产出攻击结论；用户证据推翻自己的初衷时，明确指出，并提出可成立的调整方向。

如果同行说法在当前范围内成立，可以承认它，继续找遗漏条件、论据或实际做法。没有真实增量时说“当前材料尚未形成有依据的差异”，给出最关键的补充方向。不要为了交作业制造非共识。

## 5. 如何批评与拉开比较

用户要求抨击或拉踩时，可以保留明确、尖锐的论点。把批评落在具体主张、推理、证据、承诺或可比较结果上。

形成短的论证链：对方实际说了什么 → 哪个环节不成立或适用范围过宽 → 我们的依据 → 更可靠的判断或做法。

只有“理由不足”时批评其论证不足，不能宣称结论已假。反驳一条观点不自动否定对方全部内容；同样不能把本方一条正确判断扩成全面优越。

如比较结果，先确认对象、目标、条件、时间和指标可比。无法比较时指出具体缺口，不捏造输赢。涉及动机、欺骗、业绩等现实事实，应有相应证据，不能由“观点错了”推断“他故意骗人”。

不把有证据的分歧稀释成礼貌套话，也不把人身贬低当作论据。用户要的是有力量的观点，批评力度应来自具体错误与后果。

## 6. 给出两项独立状态

**依据状态**：当前依据支持的判断／有条件支持／待验证假设／现有材料反对。说明关键依据，避免伪精确评分。

**差异状态**：相对已给样本存在差异／有来源支持特定范围的非共识／与对照结论相同但增加论据或条件／尚不能判断差异。

仅当非共识判断或具体反驳成为本篇主线时，交接必要比较范围、实际分歧及依据状态；其他任务不自动附同行分析。两项都有相应依据时，可称“当前材料支持的非共识判断”，同时保留范围与可推翻条件；不颁发“绝对正确”的认证。
